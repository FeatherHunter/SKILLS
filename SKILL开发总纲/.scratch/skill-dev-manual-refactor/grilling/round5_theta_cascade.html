θ 的连锁后果 · 判定真空

θ 删了附录 D,砍掉的是什么?

附录 D 原文列了 6 种"不该 Skill 化"的情形:单条 CRUD / 高频无视觉 / 后台管理 / 数据采集 / 一次性脚本 / 2 步内查询。它是总纲里唯一告诉读者"什么时候不该用 Skill 框架"的章节。

你选 θ 删它,理由是"ADR-0002 说所有 Skill 都要 5 层,附录 D 列'不该 Skill 化' = 多余"。但这个推理有个漏洞:附录 D 不是在说"小 Skill 可简化",是在说"有些需求根本不该用 Skill 框架,该写普通脚本"。删了附录 D,不等于所有需求都该 Skill 化——而是总纲不再告诉读者"什么需求该用普通脚本"。

这制造了一个判定真空:删了附录 D 后,当用户的需求"不该 Skill 化"时,总纲没有指引。我用 3 个场景压测这个真空。

场景 1 · AI 接到"写个记喝水脚本"的请求,走哪条路?

判定真空 审查报告未碰 AI 没有判定依据

压测

用户对 AI 说:"帮我写个记喝水的脚本。"

路径AI 行为θ 删附录 D 后的问题
路径 A · AI 默认 Skill 化AI 按 §02 建 5 层 5 文件 + §07 HELP + §05 FAT用户说"脚本",AI 给"Skill"。词不达意。且 80 行功能配 300 行合规
路径 B · AI 默认普通脚本AI 写 1 个 .py 脚本但总纲没告诉 AI"什么情况该走普通脚本"。AI 凭什么判?用户可能就是要 Skill 化(为统一管理 / 触发词)
路径 C · AI 反问用户"你要 Skill 化还是普通脚本?"用户大概率不知道区别。AI 也没有判定标准告诉用户"什么情况该选哪个"

核心问题:附录 D 不是"逃生口",是判定指南。删了它,AI 和用户都没有"是否该 Skill 化"的判定依据。总纲变成了"只管怎么写 Skill,不管该不该写"——但现实里大量需求不该 Skill 化。

你选 θ 的原意可能是"别给逃生口"。但 θ 的实际效果是"删掉了判定指南",不是"堵死了逃生口"。这两件事不一样。

决策点 7 · 判定真空怎么填

θ 删附录 D 制造了"是否该 Skill 化"的判定真空。3 种填法:

ο · 附录 A 升级为"是否该 Skill 化"的唯一判定

附录 A(3 维度评估:复用频率 / 视觉密度 / 改造阻力)原来只管"已有 Skill 是否值得改造"。升级后同时管"新需求是否该 Skill 化"。S/A/B/不做 四档覆盖新建+改造。附录 A 标题改"是否该 Skill 化 + 改造优先级判据"。单一事实源。

π · §02 开头加"Skill 化判据"小节

§02 开头加一节:"什么需求该 Skill 化:≥ 5 个唤醒词含多字段+多条目+视觉密度(对应原 §04 原则 0 判据)"。这个判据原来散落在 §04 原则 0,集中到 §02 入口。附录 D 删掉后,§02 成唯一入口。

ρ · 维持真空(真删附录 D,不补)

承认总纲"只管怎么写 Skill,不管该不该写"。判定是否该 Skill 化 = 用户/AI 的常识,总纲不介入。后果:AI 接到"记喝水脚本"会硬上 5 层 5 文件(因为没有"别 Skill 化"指引)。作者接受这个后果。

场景 2 · 附录 A 被迫独扛"是否该 Skill 化"判定

附录 A 责任膨胀 审查报告未碰 原附录 A 只管改造,现在要管新建?

如果你选 ο(附录 A 升级),会引出新问题。原附录 A 的 3 维度(复用频率 / 视觉密度 / 改造阻力)是为改造已有 Skill设计的——"改造阻力"维度假设已有 Skill 存在。但新建 Skill 时没有"改造阻力"可言。

维度改造场景(原附录 A)新建场景(ο 升级后)冲突?
复用频率已有 Skill 用户每周调几次新需求预测每周会用几次可复用,但"预测"比"实测"难
视觉密度已有 Skill 的 HTML 多字段+多条目新需求是否需要视觉可复用
改造阻力CLI 是否容易 JSON 化无 CLI 存在,无阻力可言冲突

所以 ο 不是简单"升级",是重写附录 A 的第三维度。新建场景的第三维度应该是"实现复杂度"或"领域边界清晰度",不是"改造阻力"。

决策点 8 · 附录 A 第三维度怎么改(仅当你选 ο)

如果你选 ο,附录 A 第三维度需要分场景:

σ · 第三维度按场景分裂

附录 A 第三维度:改造场景用"改造阻力",新建场景用"领域边界清晰度"(需求能否画出清晰 5 层职责)。两套判据共存于附录 A。

τ · 删除第三维度,只留 2 维度

附录 A 简化为 2 维度(复用频率 + 视觉密度)。S/A/B/不做 4 档按 2 维度组合判定。简单但粒度粗。

如果你选 π 或 ρ,决策点 8 跳过。

场景 3 · 附录 A 的"不做"档 vs §02 强制 5 层

无论你选 ο/π/ρ,只要附录 A 保留(ο/π 都保留),它的"不做"档就和 ADR-0002 有字面冲突:

来源表述含义
