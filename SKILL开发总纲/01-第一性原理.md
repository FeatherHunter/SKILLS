# 01 · 第一性原理

> 1 段话 + 1 张图。读完后你应该能向任何人 30 秒内讲清"Skill 是什么"。

## Skill 是什么

**Skill = 领域 + 工具 + 文档 + 规则**。一个 Skill 定义一整个领域(如某家庭物品管理 Skill),包含该领域的所有:

- **实体** — 物品 / 分类 / 位置 / 标签
- **操作** — 增删改查 / 统计 / 联动
- **规则** — 硬规则(系统强制)+ 软规则(AI 自觉)
- **接口** — CLI / JSON / 错误码
- **文档** — SKILL.md / HTML 镜像 / references

> HELP 唤醒词、场景资产和 HELP HTML 共同构成 Skill 的**对外可发现性入口**：用户手里的 HELP 页面、唯一场景资产、稳定的执行 prompt 三者一致才算“完整”。详见 [07-HELP与场景完备性.md](./07-HELP与场景完备性.md)。

> 没有 Skill 的 Agent = 空有厨艺没有工具的厨师。

## 为什么分层

不分层的 Skill 短期能跑,分层的 Skill 长期能活。"层"的作用只有一个:**让你写代码时知道往哪放**。
