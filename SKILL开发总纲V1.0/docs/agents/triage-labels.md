# Triage 标签

工程类 skill 用 5 个 canonical triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需评估此 issue |
| `needs-info` | `needs-info` | 等待提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全规约,可交给 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当某个 skill 提到某个角色(如"打上 AFK-ready 的 triage 标签"),使用本表对应的标签字符串。

如需改用别的词汇,编辑右列即可。
