# Architecture Decision Records (ADR)

本目录存放仓库级的架构决策记录。各技能子目录可维护各自的 `docs/adr/` 存放专属决策。

## 命名规范

- 文件命名：`NNNN-title-slug.md`，序号从 `0000` 起，按创建时间递增
- 示例：`0001-use-github-issues-as-tracker.md`

## 模板

```markdown
# <标题>

**状态**：接受 | 草案 | 废弃
**决策者**：<谁做出此决策>
**日期**：<YYYY-MM-DD>
**相关 issue**：<GH issue 编号>

## 背景
<!-- 为什么要做出这个决策 -->

## 决策
<!-- 实际做了什么决定 -->

## 后果
<!-- 积极的和消极的后果 -->
```

## 规则

- 每次解决术语冲突或架构选择时，检查是否已有相关 ADR；没有则新建
- 若已有 ADR 但结论过时，更新旧 ADR 的状态为「废弃」并新建替代 ADR
- 跨技能决策放根 `docs/adr/`；技能专属决策放 `<技能>/docs/adr/`
