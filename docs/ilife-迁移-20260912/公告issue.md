## 📢 停止开发公告 · 技能本体迁往 ilife 新仓

本仓（`FeatherHunter/SKILLS`）下列内容**已经停止开发**，相关 issue 已于 **2026-09-12 一次性全部关闭**（共 29 张）：

> 跨技能 · 公共组件 · 卡路里 · 作息管家 · 私家大厨 · 饼干记账 · 备忘录

### 新项目地址：https://github.com/FeatherHunter/ilife

在 ilife 仓里，原 SKILLS 的技能被**重构为 TypeScript 项目**（`packages/skill-*`），并在此基础上**开发了 DSH 插件**（`packages/plugin-*-ilife`）—— 插件负责把技能能力注册给 DSH 会话。

**能力没有消失，只是换了家、换了实现方式。**

## 这对你意味着什么

| 你想做的事 | 该去哪 |
|---|---|
| 提新需求 / 报缺陷（上面这几项） | [ilife 仓 issues](https://github.com/FeatherHunter/ilife/issues) |

| 看本次关闭的完整清单与理由 | `docs/ilife-迁移-20260912/README.md` |

## 本仓怎么处置

- 相关技能目录（`卡路里/`、`作息管家/`、`私家大厨/`、`饼干记账/`、`备忘录/`、`公共组件/`）：**冻结**，作为历史资产保留，不再演进。
- 这些目录下的 `.scratch/` 决策档案：**冻结保留**，历史决策仍可回溯。
- 本仓继续保留的是**其它技能**与其它工程产物。

## 关闭口径（可复核）

- 关闭理由：`not planned`（停止开发，不是「已完成」）
- 标签：加 `wontfix`；摘掉 `ready-for-agent` / `ready-for-human` / `needs-triage` / `needs-info`；保留 `skill:*` 与分类标签便于历史检索
- 每张被关的票上都有中文说明，含新仓地址与后续去处
- 执行脚本（含 `-DryRun` 预演、幂等跳过）：`docs/ilife-迁移-20260912/close-issues.ps1`
