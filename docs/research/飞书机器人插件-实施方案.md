# 飞书机器人插件 · 实施方案（动态插件原型版）

> 目标：让 DeepSeek Harness（DSH，即本机运行的这套系统）通过飞书开发者平台创建的机器人，与飞书用户**双向收发消息**：
> - 飞书私聊 / 群聊 @机器人 → 消息进入 DSH agent 会话 → agent 回复流式发回飞书。
> - 验证方式：**动态插件原型**（cordis「创造模式」会话内即时编写，浏览器批准即运行），跑通后再正式化为静态插件。
>
> 状态：**代码已就绪**（2026-08-13）· 前置：用户已有 app_id / app_secret，机器人能力已开启。
> 协议来源：`docs/research/_feishu-protocol-调研草稿.md`（官方 Go/Python SDK + 两个独立 Rust 实现 + 官方 .proto + 官方文档，五源交叉验证）。

---

## 1. 总体架构（双向链路）

```
飞书用户 ──发消息──▶ 飞书开放平台 ──长连接推送──▶ DSH 进程内的插件（host 半）
                                                      │
                           ① 收到 im.message.receive_v1 事件（WS data 帧）
                           ② 按 chat_id/open_id 找/建 DSH 会话（ctx.agents）
                           ③ 用户消息注入 agent
                           ④ 监听 session/event 拿 assistant 输出
                           ⑤ 调 im/v1/messages API 发回飞书对话
飞书用户 ◀──收到回复── 飞书开放平台 ◀──HTTP API── DSH 进程内的插件
```

- **收**：飞书**长连接（WebSocket）事件订阅**——只需出网，无需公网 URL。
- **发**：`im/v1/messages` API（tenant_access_token 鉴权），文本消息起步。
- **会话映射**：私聊 `feishu-p2p-<openid>`，群聊 `feishu-group-<chatId>`；与 Web GUI 共用同一套 DSH 会话。

## 2. 前置准备（飞书开发者平台操作清单）

1. 应用 →「事件与回调」→ 订阅方式选 **「使用长连接接收事件」**；
   ⚠️ **官方要求保存时已有在线长连接客户端**（报「无在线长连接」）。解决：先在后台选好但暂不保存，按第 5 节把插件跑起来（握手只需凭据，不依赖订阅配置），然后回后台保存；之后再发消息测试。
2. 添加事件：**`im.message.receive_v1`（接收消息）**。
3. 权限管理加 scope（以平台当前界面为准）：`im:message`、`im:message.group_at_msg:readonly`、`im:message.p2p_msg:readonly`、`im:message.send_as_bot`。
4. **创建版本并发布**（新配置才生效）。
5. 机器人拉进测试群；准备好 app_id / app_secret。

## 3. 飞书长连接协议要点（已五源验证，勿用网上旧教程）

| 主题 | 结论 |
|---|---|
| 帧编码 | WS **binary** 消息，proto2 protobuf `Frame`：`SeqID(1,u64)` `LogID(2,u64)` `service(3,i32)` `method(4,i32)` `headers(5,repeated{1:key,2:value})` `payload_encoding(6)` `payload_type(7)` `payload(8,bytes)` `LogIDNew(9)` |
| method 枚举 | **只有 0=control（ping/pong）与 1=data（event/card）**；⚠️ 网上流传的 `client_register/server_ping/client_pong/server_ack` 等枚举**不存在**，勿采用 |
| 握手 | `POST {base}/callback/ws/endpoint`，**无 Authorization 头**，body 大写驼峰：`{"AppID","AppSecret","ClientAssertion":""}`；响应 `data.URL`（query 带 `service_id`，须回填到每个帧的 `service` 字段）+ `data.ClientConfig`（PingInterval 默认 120s、重连参数） |
| 连接后 | **不发注册帧**。收包循环 + ping 循环（首个 ping 立即发，之后每 PingInterval 秒）；帧类型看 header `type`（event/card/ping/pong） |
| 事件 payload | data 帧 `payload`(8) = **UTF-8 JSON**（事件体）；v2.0 事件顶层 `header.event_type`；分片用 header `sum/seq/message_id`，sum>1 按 message_id 缓存 5 秒到齐拼接 |
| ACK | 收到 data 帧**原样 echo**（SeqID/LogID/service/method/headers 不变 + 追加 header `biz_rt=<毫秒>`），payload 换成 `{"code":200,"headers":null,"data":null}`；3 秒内不回按 15s/5min/1h/6h 重推最多 4 次；**可能重复**（幂等键 v2.0=`header.event_id`） |
| 心跳 | 客户端发 ping（method=0，header type=ping）；服务端 pong 的 **payload 非空时是新的 ClientConfig JSON，必须解析**（服务端可中途改配置）；收到服务端 ping 不回 |
| 配置约束 | 仅**企业自建应用**；单应用最多 50 连接；集群模式（多客户端随机一个收）；长连接内置加密鉴权，无需验签解密；`type=card` 帧不回 ACK（旧版卡片回调不支持长连接） |
| 重连 | 官方 SDK 无限重连（ReconnectCount=-1），间隔 ReconnectInterval（默认 120s）+ 首次随机抖动；重连前重新握手拿新 URL |

## 4. 动态插件代码（host 半，可直接用）

> 使用方式：在「创造模式」会话里让 agent 执行 `cordis_define` 提交下面的 `code.host`（client 半留空），然后 `cordis_run`。
> 运行前必做：`cordis_inspect` 核对两处——① builtins 里 `fetch`/`WebSocket` 是否可用；② 下方标 `【核对】` 的 DSH 集成 API 签名。

```js
// ============================================================
// feishu-bridge —— 飞书长连接 ↔ DSH 双向桥接（code.host）
// 纯 JS 函数体：无 import/require/JSX；全局仅用 fetch/WebSocket/TextEncoder 等
// ============================================================
return {
  name: 'feishu-bridge',
  inject: ['agents', 'timer'],          // timer 提供 ctx.timeout/ctx.interval
  apply(ctx) {
    // ---------- 配置（原型期直接填；正式版改走设置/环境变量） ----------
    const APP_ID = 'cli_xxxxxxxx'                     // ← 填你的
    const APP_SECRET = 'xxxxxxxxxxxxxxxx'             // ← 填你的
    const FEISHU_BASE = 'https://open.feishu.cn'      // 国际版: https://open.larksuite.com
    const ALLOWED_OPEN_IDS = []                       // 空 = 放行全部（原型）；建议填 ['ou_xxx']
    // ---------- 运行时自检（沙箱可能拦截全局，先确认） ----------
    if (typeof fetch !== 'function') return void console.error('[feishu-bridge] fetch 不可用：先 cordis_inspect builtins')
    if (typeof WebSocket !== 'function') return void console.error('[feishu-bridge] WebSocket 不可用：先 cordis_inspect builtins')

    // ================= protobuf 最小编解码（pbbp2.proto Frame） =================
    const enc = new TextEncoder(), dec = new TextDecoder()
    function varintPush(out, v) {                     // v 支持到 2^53（够用）
      v = Math.floor(Number(v))
      while (v >= 0x80) { out.push((v % 128) | 0x80); v = Math.floor(v / 128) }
      out.push(v)
    }
    function readVarint(buf, pos) {
      let r = 0, s = 0, b
      do { b = buf[pos++]; r += (b & 0x7f) * 2 ** s; s += 7 } while (b & 0x80 && s < 64)
      return [r, pos]
    }
    function encodeHeader(k, v) {
      const o = []
      varintPush(o, 1 * 8 + 2); { const b = enc.encode(k); varintPush(o, b.length); o.push(...b) }
      varintPush(o, 2 * 8 + 2); { const b = enc.encode(v); varintPush(o, b.length); o.push(...b) }
      return o
    }
    function encodeFrame(f) {
      const o = []
      varintPush(o, 1 * 8 + 0); varintPush(o, f.SeqID)
      varintPush(o, 2 * 8 + 0); varintPush(o, f.LogID)
      varintPush(o, 3 * 8 + 0); varintPush(o, f.service)
      varintPush(o, 4 * 8 + 0); varintPush(o, f.method)
      for (const h of f.headers) { varintPush(o, 5 * 8 + 2); const b = encodeHeader(h.key, h.value); varintPush(o, b.length); o.push(...b) }
      if (f.payload) { varintPush(o, 8 * 8 + 2); varintPush(o, f.payload.length); o.push(...f.payload) }
      return Uint8Array.from(o).buffer
    }
    function decodeFrame(buf) {
      const f = { SeqID: 0, LogID: 0, service: 0, method: 0, headers: [], payload: null }
      let pos = 0
      while (pos < buf.length) {
        const [tag, p1] = readVarint(buf, pos); pos = p1
        const field = Math.floor(tag / 8), wire = tag % 8
        if (wire === 0) {
          const [v, p2] = readVarint(buf, pos); pos = p2
          if (field === 1) f.SeqID = v; else if (field === 2) f.LogID = v
          else if (field === 3) f.service = v; else if (field === 4) f.method = v
        } else if (wire === 2) {
          const [len, p2] = readVarint(buf, pos); pos = p2
          if (field === 5) {
            const hb = buf.slice(pos, pos + len); let hp = 0, h = {}
            while (hp < hb.length) {
              const [ht, q1] = readVarint(hb, hp); hp = q1
              const hf = Math.floor(ht / 8)
              const [hl, q2] = readVarint(hb, hp); hp = q2
              const hv = dec.decode(hb.slice(hp, hp + hl)); hp += hl
              h[hf === 1 ? 'key' : 'value'] = hv
            }
            f.headers.push(h)
          } else if (field === 8) f.payload = buf.slice(pos, pos + len)
          pos += len
        } else break // 未知 wire type，宽容跳过（原型足够）
      }
      return f
    }
    const hdr = (f, k) => { const h = f.headers.find(x => x.key === k); return h ? h.value : undefined }

    // ================= 握手与发消息 =================
    async function getConnUrl() {
      const r = await fetch(FEISHU_BASE + '/callback/ws/endpoint', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', locale: 'zh' },
        body: JSON.stringify({ AppID: APP_ID, AppSecret: APP_SECRET, ClientAssertion: '' }),
      })
      const j = await r.json()
      if (j.code !== 0) throw new Error('[feishu-bridge] endpoint 失败 code=' + j.code + ' ' + (j.msg || ''))
      return j.data // { URL, ClientConfig }
    }
    let tokenCache = { token: null, exp: 0 }
    async function tenantToken() {
      if (tokenCache.token && Date.now() < tokenCache.exp - 60000) return tokenCache.token
      const r = await fetch(FEISHU_BASE + '/open-apis/auth/v3/tenant_access_token/internal', {
        method: 'POST', headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ app_id: APP_ID, app_secret: APP_SECRET }),
      })
      const j = await r.json()
      if (j.code !== 0) throw new Error('[feishu-bridge] token 失败 code=' + j.code)
      tokenCache = { token: j.tenant_access_token, exp: Date.now() + (j.expire || 7200) * 1000 }
      return tokenCache.token
    }
    async function sendText(chatId, text) {
      const t = await tenantToken()
      const r = await fetch(FEISHU_BASE + '/open-apis/im/v1/messages?receive_id_type=chat_id', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', Authorization: 'Bearer ' + t },
        body: JSON.stringify({ receive_id: chatId, msg_type: 'text', content: JSON.stringify({ text }) }),
      })
      const j = await r.json()
      if (j.code !== 0) console.error('[feishu-bridge] 发送失败 code=' + j.code, j.msg)
      return j.code === 0
    }

    // ================= 长连接客户端 =================
    let ws = null, serviceId = 0, pingInterval = 120, running = true
    const partsCache = new Map()          // 分片重组缓存: message_id -> {parts, at}
    const seenEvents = new Set()          // 幂等: header.event_id
    let pingTimer = null, reconnectTimer = null, nextReconnectDelay = 5000

    function sendFrame(f) { if (ws && ws.readyState === 1) ws.send(encodeFrame(f)) }
    function sendPing() { sendFrame({ SeqID: 0, LogID: 0, service: serviceId, method: 0, headers: [{ key: 'type', value: 'ping' }], payload: null }) }
    function ack(f, ms) {
      sendFrame({ SeqID: f.SeqID, LogID: f.LogID, service: f.service, method: f.method,
        headers: [...f.headers, { key: 'biz_rt', value: String(ms) }],
        payload: enc.encode(JSON.stringify({ code: 200, headers: null, data: null })) })
    }
    function scheduleReconnect() {
      if (!running) return
      reconnectTimer = ctx.timeout(async () => {
        console.log('[feishu-bridge] 重连（延迟 ' + nextReconnectDelay + 'ms）')
        nextReconnectDelay = Math.min(nextReconnectDelay * 2, 60000)
        await connect()
      }, nextReconnectDelay)
    }
    async function connect() {
      try {
        const data = await getConnUrl()
        serviceId = parseInt(new URL(data.URL).searchParams.get('service_id') || '0', 10)
        pingInterval = data.ClientConfig?.PingInterval || 120
        ws = new WebSocket(data.URL)
        ws.binaryType = 'arraybuffer'
        ws.onopen = () => {
          console.log('[feishu-bridge] 已连接 service=' + serviceId + ' ping=' + pingInterval + 's')
          nextReconnectDelay = 5000
          sendPing()                                    // 首个 ping 立即发
          if (pingTimer) pingTimer()
          pingTimer = ctx.interval(sendPing, pingInterval * 1000)
        }
        ws.onmessage = (e) => {
          const f = decodeFrame(new Uint8Array(e.data))
          if (f.method === 0) {                         // control: pong（带新 ClientConfig）
            const h = hdr(f, 'type')
            if (h === 'pong' && f.payload && f.payload.length) {
              try {
                const cfg = JSON.parse(dec.decode(f.payload))
                if (cfg.PingInterval && cfg.PingInterval !== pingInterval) {
                  pingInterval = cfg.PingInterval
                  if (pingTimer) pingTimer()
                  pingTimer = ctx.interval(sendPing, pingInterval * 1000)
                  console.log('[feishu-bridge] 服务端更新 PingInterval=' + pingInterval)
                }
              } catch (err) { /* 忽略坏配置 */ }
            }
            return
          }
          const type = hdr(f, 'type')
          if (type === 'card') return                    // 卡片帧不回 ACK
          if (type !== 'event') return
          const t0 = Date.now()
          // ---- 分片重组 ----
          const sum = parseInt(hdr(f, 'sum') || '1', 10), seq = parseInt(hdr(f, 'seq') || '0', 10)
          const mid = hdr(f, 'message_id') || ''
          let payload = f.payload
          if (sum > 1) {
            let buf = partsCache.get(mid)
            if (!buf) { buf = { parts: new Array(sum), at: Date.now() }; partsCache.set(mid, buf) }
            buf.parts[seq] = f.payload
            if (buf.parts.some(p => !p)) return          // 未齐，本次不回 ACK，等后续包
            const total = buf.parts.reduce((a, b) => a + b.length, 0)
            payload = new Uint8Array(total)
            let off = 0
            for (const p of buf.parts) { payload.set(p, off); off += p.length }
            partsCache.delete(mid)
          }
          // 清理 5 秒前的分片缓存
          for (const [k, v] of partsCache) if (Date.now() - v.at > 5000) partsCache.delete(k)
          try {
            const json = JSON.parse(dec.decode(payload))
            const eventId = json.header?.event_id || json.uuid || ''
            if (eventId && seenEvents.has(eventId)) return   // 幂等去重
            if (eventId) seenEvents.add(eventId)
            handleEvent(json)                                 // 异步处理，不阻塞 ACK 太久
            ack(f, Date.now() - t0)
          } catch (err) {
            console.error('[feishu-bridge] 事件处理失败', err)
            sendFrame({ SeqID: f.SeqID, LogID: f.LogID, service: f.service, method: f.method,
              headers: [...f.headers, { key: 'biz_rt', value: String(Date.now() - t0) }],
              payload: enc.encode(JSON.stringify({ code: 500, headers: null, data: null })) })
          }
        }
        ws.onclose = () => { console.log('[feishu-bridge] 连接关闭'); if (pingTimer) pingTimer(); pingTimer = null; scheduleReconnect() }
        ws.onerror = () => { try { ws.close() } catch (e) {} }
      } catch (err) {
        console.error('[feishu-bridge] 连接失败', err)
        scheduleReconnect()
      }
    }

    // ================= 事件 → DSH 会话（核心桥接） =================
    function extractText(message) {
      if (message.message_type !== 'text') return ''        // 原型只处理文本
      try { return JSON.parse(message.content).text || '' } catch (e) { return '' }
    }
    function isMentioned(message) {
      return Array.isArray(message.mentions) && message.mentions.length > 0   // 原型：群聊有 mentions 即视为 @（可细化比对 bot open_id）
    }
    async function handleEvent(json) {
      const ev = json.event
      if (!ev || ev.type !== 'im.message.receive_v1') return
      const msg = ev.message, sender = ev.sender
      if (!msg || !sender) return
      const isGroup = msg.chat_type === 'group'
      if (isGroup && !isMentioned(msg)) return
      const openId = sender.sender_id?.open_id
      if (ALLOWED_OPEN_IDS.length && !ALLOWED_OPEN_IDS.includes(openId)) return
      const text = extractText(msg)
      if (!text) return
      const key = isGroup ? 'feishu-group-' + msg.chat_id : 'feishu-p2p-' + openId
      console.log('[feishu-bridge] 收到消息 session=' + key + ' text=' + text.slice(0, 50))
      await feedAgent(key, text, msg.chat_id, msg.message_id)
    }

    // ---------- 【核对】DSH 集成点：以 cordis_inspect 实测签名为准 ----------
    // 核对方法（创造模式会话内执行）：
    //   cordis_inspect what:api name:agents      → agents.create/resume/get 的真实签名
    //   cordis_inspect what:events               → 会话事件名（找 assistant 输出事件）
    // 社区已验证路径：ctx.agents.create({sessionId, agentOptions:{provider,model}, meta:{cwd}})
    //                 + ctx.on('session/event') 过滤本插件 sessionId
    const ACTIVE = new Map()   // key -> { chatId, session }
    async function feedAgent(key, text, chatId, msgId) {
      try {
        const agents = ctx.get('agents')
        if (!agents) return void console.error('[feishu-bridge] agents 服务不可用')
        let entry = ACTIVE.get(key)
        if (!entry) {
          let session = agents.get(key)                    // 【核对】取会话方法名
          if (!session) session = await agents.create({    // 【核对】create 签名与字段
            sessionId: key,
            agentOptions: { provider: undefined, model: undefined },  // 【核对】不填是否用默认路由
            meta: { cwd: undefined },
          })
          entry = { chatId, session }
          ACTIVE.set(key, entry)
        }
        // 【核对】注入用户消息的方法（可能叫 agents.send / session.pushUser / agent-loop 的某方法）
        // 原型兜底：若找不到注入 API，至少保持连接与日志，等核对后补上这一步
        console.log('[feishu-bridge] 注入消息:', JSON.stringify({ key, text, msgId }))
        // await agents.send?.(entry.session, { role: 'user', content: text })   // ← 核对后启用
      } catch (err) {
        console.error('[feishu-bridge] feedAgent 失败', err)
        await sendText(chatId, '⚠️ 桥接出错：' + String(err && err.message || err).slice(0, 200))
      }
    }
    // 【核对】会话输出事件名（社区用 session/event + assistant/message）
    ctx.on('session/event', (ev) => {
      const key = ev.sessionId   // 【核对】事件对象里会话标识的字段名
      const entry = ACTIVE.get(key)
      if (!entry) return
      if (ev.type === 'assistant/message' && typeof ev.text === 'string') {   // 【核对】字段名
        sendText(entry.chatId, ev.text)
      }
    })

    // ================= 生命周期 =================
    ctx.on('dispose', () => {
      running = false
      if (pingTimer) pingTimer()
      if (reconnectTimer) reconnectTimer()
      if (ws) { try { ws.close() } catch (e) {} }
      ACTIVE.clear()
      console.log('[feishu-bridge] 已卸载')
    })
    connect()
  },
}
```

## 5. 运行步骤（在 DSH 里跑起来）

1. **新建「创造模式」会话**：DSH Web GUI → 新建会话 → agent 预设选 **cordis（创造模式）**（动态插件工具集只在该预设下挂载）。
2. 在该会话里对 agent 说：
   - "按 `docs/research/飞书机器人插件-实施方案.md` 第 4 节的代码，先 `cordis_inspect` 核对 builtins（fetch/WebSocket）与 agents/session 事件 API 签名，然后 `cordis_define` + `cordis_run` 运行 feishu-bridge 插件"（**浏览器弹批准框，点确认**；代码里 `cli_xxxxxxxx` 两个占位符换成你的真实凭据）。
3. 若后台「保存长连接配置」报「无在线长连接」：插件已连接后回后台保存（先有在线客户端才能保存成功）。
4. **测试**：飞书私聊机器人发"你好" → DSH 会话列表出现 `feishu-p2p-<openid>` 会话 → 回复发回飞书。
5. 调试：`cordis_inspect_self` 看诊断；改代码 → `cordis_define` 新 Package → `cordis_run`（update 模式）。

## 6. 风险与正式化路径

| 风险/问题 | 应对 |
|---|---|
| 动态沙箱无 fetch/WebSocket | 改走静态插件 + 官方 Node SDK（`@larksuiteoapi/node-sdk` 内置长连接/重连/ACK） |
| 【核对】项（agents 注入 API、事件名）签名不符 | 以创造模式会话内 `cordis_inspect` 实测为准修改；社区 dsh-feishu-bot 的调研（`_feishu-bot-调研草稿.md`）可作参考路径 |
| 凭据明文 | 原型期先跑通；正式版走环境变量/设置服务，避免明文进会话记录 |
| 外部输入安全 | 填 `ALLOWED_OPEN_IDS` 白名单；群聊仅 @；agent 自带沙箱/审批栈 |
| 消息重复/乱序 | 幂等键 `header.event_id` 去重（代码已含）；分片按 seq 拼接 |
| 出站仅文本 | 后续升级 interactive 卡片（msg_type=interactive） |
| 官方 API 破坏性变更 | 以运行时 `cordis_inspect` 为准；代码集中在方案文档便于升级 |

**正式化**：原型跑通后，把本代码迁移为静态插件（npm 包/本地目录 + `cordis.patch.yml` 行 + 常驻重连），或将凭据/白名单/配置外置到 `~/.dsh/settings.yaml`。
