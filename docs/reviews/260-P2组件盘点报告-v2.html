关键差异（统一前的障碍点）

  • 数据源 3 类 4 种模式：单文件自权威（备忘录）/ 分文件+合并器→总账（居家·大厨·饼干·作息）/ 双源合并渲染（卡路里：scene_data JSON 优先 + _triggers.py 补齐，同 wake_word 411 条、prompt 冲突仅 1 条、仅单源 59 条）——统一需要先定义「谁是渲染唯一入口」
  • 分组层级不一致：一级（备忘录·作息）/ 二级 category+subfunction 或 domain+sub（卡路里·居家·大厨）/ 三级 subs→wake_words→scenes（饼干记账）——HELP 分组导航需要统一层数
  • 字段命名漂移：scenario_id vs id vs key；prompt vs prompt_template；HTML 映射 html_template（顶层）vs html.template（嵌套）
  • status 语义 5 技能一致（''=可用 / 【待开发】=禁用），卡路里无 status 字段
  • 卡路里独有 data_fields / depends_on_external / order；其余技能有 dimensions（采集维度）——卡路里用 fill_hints
  • 私家大厨独有全局元信息（prompt_rules/methodology/boundary_templates）——HELP 渲染需要这些支撑
  • 居家管家 SM4/SM7/SM9 无 scenes 分文件（9 域只有 6 个文件），总账却含其场景——域分文件覆盖不完整

统一 scene_data 结构草案（对齐 help-template-contract §3）

统一结构 = 渲染器只认这一种输入；各技能数据经归一化层转换（源字段 → 统一字段），转换层放 Base。

# 统一 scene_data 结构 v1（Base 渲染器输入契约）
{
  "skill_name": "技能中文名",          // 必填 · 标题/文件名
  "title": "能力速查台",             // 必填 · 页面大标题
  "subtitle": "一句话说明",          // 可选
  "groups": [                      // 分组导航 · 层级统一为 2 级（category→subfunction）
    { "id": "diet", "label": "饮食", "count": 69 }
  ],
  "scenes": [                     // 场景卡片 · 归一化后
    {
      "id": "diet_add_meal",         // 源: key / id / scenario_id
      "category": "diet",          // 源: category+subfunction / domain+sub / subs.name
      "title": "记一餐",            // 源: name / scenario_title
      "wake_word": "记一餐",       // 全部技能一致
      "prompt_template": "…",    // 源: prompt / prompt_template · 定稿零差异
      "status": "",                // ''可用 / 【待开发】禁用 · 卡路里补默认''
      "editable_fields": []         // 可选 · 源: fill_hints / dimensions（参数化场景）
    }
  ]
}

# CHARTS-HELPERS v1 接口草案（收敛 4 形态）
charts = window.__charts  // 命名空间

charts.bar(el, data, opts?)      // 柱状 · 居家管家已有 · 数据 [{label,value,sub?}]
charts.line(el, series, opts?)   // 折线 · 饼干记账 analysis_view 形态 · series [{name,points:[{x,y}]}]
charts.donut(el, segments, opts?) // 环形 · 饼干记账 donut 形态 · segments [{label,value,color?}]
charts.progress(el, pct, opts?)  // 进度条 · 居家/作息 bar-fill 形态 · pct 0-100

// 统一约束
// · 纯 CSS+SVG 无外部依赖 · 手机 375px 适配 · 语义色走 token A 组
// · 输入校验：数据空 → 渲染 emptyState（与状态层联动）
// · 数据驱动渲染：技能侧不再手写 SVG 模板字符串

// 白名单例外
// · weight_volatility_v2 canvas（波动图特殊交互）留技能自营，走公共层 ISSUE 审批
