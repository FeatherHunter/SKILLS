医药国际注册 · 并行/串行编排设计

第一性原理 · 适用 6 方法论全场景
判据先行：可并行 = 无数据依赖 + 无共享可变状态 + 成果可独立验收，三条件同满足；必须串行 = 数据流依赖 / 统一决策口径 / 外部实时依赖（只能等）/ 门禁关卡，任一命中。

领域关键路径（最长串行链 · 时间主线）

原料药数据 3.2.S→ Module 3→ Module 2 综述→ 核心 CTD 定稿→ 合规校验（门禁）→ 提交→ 官方审评→ 缺陷信→ 回复→ 批准

三条外部实时依赖（真正的瓶颈 · 只能提前启动不能压缩）：

⏱ 稳定性数据 6/12/24 月 ⏱ BE 试验（临床 6-12 月+） ⏱ 官方审评周期（6-24 月）

🟢 可并行（建议立即开多条线）

  • 多国法规调研：单国调研互相独立（A 类唤醒词）——但「对比国家」必须等单国调研完成
  • 稳定性试验方案 + 启动：最长依赖最早启动，与一切并行（持续迭代法的核心价值）
  • BE 试验供应商筛选/伦理递交：与资料编制并行推进
  • Module 3.2.S（原料药）‖ 3.2.P（成品）：同属 Module 3 但内容独立
  • Module 4（非临床）‖ Module 5（临床）：参比制剂/BE 数据就绪后并行
  • Module 1（行政信息）：代理商确定后随时可做，与一切并行
  • 多国差异化准备：语言翻译/公证认证/各国格式——与核心编制并行
  • 6 角色模拟分析：多角色决策法的角色分析阶段并行，辩论回合串行
  • 缺陷信按类别分派：分类后不同类别并行回复（同一类别必须统一口径）

🔴 必须串行（不可并行）

  • 决策链：调研 → 多国对比 → 选优先国家 → 注册策略 → 项目计划 → 拆任务排节点（不调研无法选国、不选国无法排计划——信息瀑布）
  • 数据链：原料药数据 → Module 3 → Module 2 综述（QOS 是 Module 3 的综述，数据未定综述必返工）→ 核心 CTD 定稿
  • 门禁：合规校验 → 提交（校验是关卡，不校验不能提交；申请人字段/文件格式/必填项/完整性/合规 5 检查按序过）
  • 官方链：提交 → 审评 → 缺陷信 → 回复 → 批准（不可跳过、官方流程不可并行）
  • 缺陷回复内部：先分析分类 → 定统一口径 → 再逐条回复 → 审核 → 提交（分析产出决定回复策略）
  • 批量编制品质关卡：流水线作业法各环节质检是关卡，不合格不流入下游

对抗式审查视角 · 4 个常见编排错误

❌ 并行编制 Module 2 与 Module 3：QOS 综述依赖 Module 3 数据，并行必返工——综述永远滞后于数据，先数据后综述。
❌ 等资料全齐才启动稳定性试验：6/12/24 个月实时依赖是整个项目最长等待，晚启动 1 天 = 批准晚 1 天。第一性原理：最长依赖最早启动。
❌ 缺陷信逐条并行回复无统一口径：同一条缺陷两种答复 = 审评官质疑一致性 → 先定口径再分派。
❌ 多国各自为政编核心 CTD：一份核心资料定稿，各国只做差异化外壳（语言/公证/格式）——否则 3 倍工作量 + 3 倍漂移风险（与 #260 同源副本漂移同构）。

一句话编排口诀

「调研选国先串行定方向，稳定性/BE 立刻启动别等；Module 1/4/5 与 3 并行，S/P 双线开工；综述等数据、校验是门禁；缺陷先定口径再分派；多国共享一份核心 CTD，只做差异化外壳。」
