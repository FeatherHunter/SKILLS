## 附注（Q2/Q3/Q5 的解释，用户要求）

- **附注 A（Q2）** `DSH_DESKTOP_COMMAND` = 自定义启动命令（整行，shell 解析）。设置后桌面版**绕过内置运行时**，直接按你写的命令启动 DSH（例：`npx --yes @deepseek-ai/dsh web --port 3080`）。你以前设过（日志有「拉起命令: npx …」），后丢失。现在内置运行时已带缓存复用 + 测速选源，不再依赖它也能秒起——是否恢复由你定。
- **附注 B（Q3）** 首次安装时若本机 npx 缓存已有 DSH，桌面版直接复制免下载；当前复制约 2 分钟（单文件串行 + 每 1.5s 全量统计目录）。优化 = 并行复制 + 增量统计（预计压到 30s 内），属首次安装速度体验，非功能缺失。
- **附注 C（Q5）** 可控端到端升级测试方案（未执行，待批准）：打包本地 `@deepseek-ai/dsh` 为高版本号 tarball（如 0.1.0-rc.99）→ 本地假 registry 伺服 → 桌面版（`DSH_DESKTOP_REGISTRY` 指向它）→ 检查更新发现新版 → 确认 → npm install @latest（真下载真安装）→ 自动重启 → 验证已装版本与日志。测完用官方源重装回真实版本。需要：`DSH_DESKTOP_APPDATA`（或等价的 runtime 目录重定向）测试钩子，或接受测试污染真实 runtime 后还原。
