04 三个技能的嵌套关系

grill-with-docs 的本质是:把 grilling 和 domain-modeling 串起来。画出来就是这种嵌套:

🌳 grill-with-docs
"Run a grilling session, using domain-modeling"
入口:用户输入 /grill-with-docs
🔥 grilling
12 行 · 决策树遍历 / 一次一问 / 推荐答案 / 等确认
算法:逐分支问问题,达成共识前不动
📚 domain-modeling
74 行 + 60 行 + 47 行 · 5 个行为 + ADR 三原则
副驱动:每次术语解决立即写 CONTEXT.md / 决定写就写 ADR

从下往上看:

  • domain-modeling 提供"如何记词汇表 + ADR"的纪律
  • grilling 提供"如何反复访谈、达成共识"的核心动作
  • grill-with-docs 把两者合起来:边访谈边落痕

05 落痕机制 · 什么时候写文件

grilling 提供"对话流",domain-modeling 提供"何时落盘"。两者在每次访谈回合的协作:

grilling 负责

  • 提出下一个问题
  • 附带推荐答案
  • 等用户答
  • 检查是否达成共识

domain-modeling 负责

  • 用术语挑战用户措辞
  • 锐化模糊概念
  • 把解决的术语立即写进 CONTEXT.md
  • 符合三原则时建议写 ADR
关键不变量:grilling 的 "Do not act until I confirm" 闸门照样生效 —— 写文件也是"行动",所以用户必须先确认共识,domain-modeling 才能落盘。

06 为什么有"with docs"这个变体?

ask-matt 主流程里讲得很清楚:

"/grill-with-docs — sharpen the idea by interview. Start here when you have a codebase: it's stateful, retaining what it learns in CONTEXT.md and ADRs. (No codebase? Use /grill-me — see Standalone.)"

翻译:

场景用谁
有 codebase,需要保留访谈成果grill-with-docs
没 codebase,纯头脑风暴grill-me
★ 设计哲学

同一套访谈动作,因为"有没有 codebase"分两条路。有 codebase 的对话天然有"留痕需求" —— 你下次再回到这个仓库,需要重新加载上下文。grill-with-docs 把这件事外包给 domain-modeling 落盘,而 grilling 本身专注访谈。

07 关键设计模式

Composition by Reference · 引用组合
grill-with-docs 不复制任何代码,只用一句 "using the /domain-modeling skill" 引用另一个技能。
One-Line Differentiation · 一行差异化
和 grill-me 只差一句,但产生"无状态 vs 落痕"完全不同的产品形态。
Two-Primitive Pairing · 双 Primitive 配对
grilling(算法) + domain-modeling(纪律) = grill-with-docs。Skill 作为"组合点"而非"实现细节"。
Stateless vs Stateful Pairing
grill-me 是 stateless,grill-with-docs 是 stateful。两个形态分别覆盖不同入口。
Document-as-Side-Effect
文档是访谈的副作用,而不是另一项工作。domain-modeling 在访谈回合中即时触发。
Confirmation Gate Preserved · 闸门保持
grilling 的"Do not act until I confirm"在 grill-with-docs 里仍然生效。文档落盘也受此约束。

08 启发 · 我们可以抄什么?

★ 给 Skill 组合设计的启示

1. 技能可以组合:7 行 wrapper + 12 行 primitive + 74 行 discipline = 完整产品。
2. 一行差异 = 一个新特性:加 "using X" 就能把无状态变有状态。
3. 不复制代码:用引用,不要 import 内容。
4. 文档是副作用,不是任务:边访谈边落盘,不另开"写文档"阶段。
5. 闸门沿用:组合新技能时,核心 primitive 的不变量要保留。
6. 命名"with X"表达差异:grill-with-docs / grill-me 一目了然。
