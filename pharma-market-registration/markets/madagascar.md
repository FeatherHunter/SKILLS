# 马达加斯加 注册要点

> last_verified: 2026-08-12（概况部分）
> 状态: 已开发市场

## 1. 概况

- 监管机构: Agence du Médicament de Madagascar (AMM，马达加斯加药品管理局)，公共行政机构（EPA），隶属卫生部（Ministère de la Santé Publique）。依据 Décret n°2010-0960 于 2010-11-30 组建（前身 Décret 98-086/SAN）
- 官网: https://amm.mg/
- 官方语言: 法语（标签/说明书/申报资料须用法语，官方文件为法语）

## 2. 注册路径

- 申报类型（进口许可/FSC/注册证）: 注册证（AMM, Autorisation de Mise sur le Marché）
- 本地代理要求: 需当地代理/官方代表（官方要求 appointment letter）；当前申请者为客户公司 PHARMATEK S.A.R.L.（Lot II R 145 B Ambohitrakely BP 8591 Antananarivo 101 - Madagascar），申请者随客户不同而变化
- 流程步骤:
  1. CTD 文件递交
  2. 法律文件贸促会认证（GMP、生产许可证、COPP、MA）
  3. 包材稿件制作与确认
  4. 样品制作
  5. 全部文件 + 样品递交
  6. 拿证：约 3 个月

## 3. 文件要求

- Dossier 格式（CTD/ACTD/自有目录）: CTD 全套；需提供 CTD List 给客户对照。SmPC 部分须为法语
- GMP / COPP / FSC / CPP: 法律文件（GMP、生产许可证、COPP、MA）**全部**需贸促会认证；生产地为中国
- 必须生产商提供的文件: CTD 相关文件、法律文件；注册起初须向工厂确认有无 DMF 文件——无 DMF 时需委托其他公司代写
- COA 要求签字并盖章
- 稳定性要求: 长期 30℃±2℃ / 65%RH±5%；加速 40℃±2℃ / 75%RH±5%

## 4. 样品要求

- 数量: 需提前问客户；**多发 2 盒**（防运输毁坏）
- 是否需要原料药样品: 需要 API 5g
- 样品 COA: 成品和原料药都需要 COA；跟随样品走，与申报资料标准一致

## 5. Artwork 要求

- 语言 / 注册号标注 / 特殊警示语: 包材稿件须为法语；内外包材需体现储存条件；客户有统一的包材图案和 logo，注册需体现红框或绿框；稿件上需体现对方公司名称

## 6. 时间与费用

- 审评周期: 从交付全部资料+样品给客户起约 3 个月拿证（客户协助申报+下证）
- 注册有效期: 5 年
- 再注册周期: 需提供补充文件及样品
- 注册费用: 待确认
- 最终拿证: 上市许可（AMM, Autorisation de Mise sur le Marché）

## 7. 常见坑

- 文件多处需要盖章和签字（不止 COA）
- 包材细节易遗漏（具体细节待补：用户后续提供文件）
- 待确认: 贸促会认证的语言是英语还是法语
- 待确认: 认证后是否需要原件
