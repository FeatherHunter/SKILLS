# 尼日利亚 注册要点

> last_verified: 2026-08-26
> 状态: 已开发市场

## 1. 概况

- 监管机构: NAFDAC（National Agency for Food & Drug Administration and Control，国家食品药品管理与控制局）（2026-08-24 用户确认，已核实）
- 官网: https://nafdac.gov.ng/ ；在线申报门户 NAPAMS: https://registration.nafdac.gov.ng （AI 联网，待确认）
- 官方语言: **英语**（2026-08-24 用户确认+官方指南印证: 申报必须英语；外语标签须加英语译文否则不注册，已核实）

## 2. 注册路径

- 申报类型: 注册证（Certificate of Product Registration，NAFDAC Registration Number）（AI 联网，待确认）
- 本地代理要求: 须尼日利亚本地代理（Superintendent Pharmacist 须有 PCN 执照、场所保留许可等由代理落地）（AI 联网，待确认）
- 流程步骤: Dossier 筛查（NAPAMS，每产品单独申请）→ 文件+标签审查 → 发样品进口许可 → 样品递交+实验室检验 → **GMP 现场检查** → FDRC 批准会议 → 发证（AI 联网官方指南，待确认）
- **⚠️ 现场审计硬门槛: 注册前必须接受尼日利亚官方（NAFDAC）来华现场审计（GMP Inspection），制造商须出具检查邀请函；很多注册因无法安排/通过现场审计而停滞**（2026-08-24 用户确认，已核实；官方指南 3.1.12 要求邀请函含工厂信息+本地代理信息，印证）

## 3. 文件要求

- Dossier 格式: **CTD 格式**（2026-08-24 用户确认，已核实；官方 CTD 指南印证: 电子版、按模块建文件夹、可检索 PDF，QIS 用 Word）
- GMP / COPP / FSC / CPP: COPP 和 cGMP 证书**须尼日利亚驻原产国使馆认证**（无尼使馆时可用英联邦/ECOWAS 国家使馆）；**中国公司特别注意: 生产许可证也须尼日利亚使馆认证**（官方指南，待确认）
- 其他关键文件（官方指南，待确认）: 商标注册证据（尼日利亚商标注册处 Class 5）；POA/合同生产协议公证；仿制药须 BE 报告或 Biowaiver（CTD 格式）；复方药须证明临床优势
- 必须生产商提供的文件: 所有的文件都是从生产商要来的，没有的会自己想办法解决（2026-08-26 用户确认，已核实；口径与科特迪瓦一致）

## 4. 样品要求

- 数量: **无公开固定数量表**——流程为「标签审查通过 → NAFDAC 发样品进口许可 → 按 NAFDAC 通知寄样」，具体数量以当次通知为准（2026-08-24 AI 联网官方指南，待确认；实操前与代理确认）
- 是否需要原料药样品: AI 联网检索（2026-08-26，待确认）——NAFDAC 官方注册流程仅要求**成品样品**用于实验室检验（发进口许可→按通知寄样），全流程未见 API 样品要求，倾向不需要；API 相关法规只涉及尼国内生产/销售的 API 进口许可，与注册寄样无关。待实操确认
- 样品 COA: 需要，COA 须用检测实验室抬头纸，含品名/批号/生产与失效日期/分析员姓名职务签字（官方指南，待确认）
- 样品拒收情形（NAFDAC 实验室指南，待确认）: 破损、同一样本批号/包装混装、封口破损、泄漏、数量不足；药品检验时限 6 周（生物制品 8 周）

## 5. Artwork 要求

- 语言: 标签外语须附英语译文，否则不予注册（官方指南，待确认）
- 标签最低要求 13 项（官方指南 8.2，待确认）: 品名+通用名、生产商全地址、**NAFDAC 注册号预留位**、批号/生产日期/失效日期、剂型与规格、适应症/频次/途径（OTC）、PIL、处方信息（POM）、净含量、活性成分单位剂量定量、必要警示、储存条件
- 标签不得与已注册产品近似，否则不注册

## 6. 时间与费用

- 审评周期（官方 SLA 2025-05，待确认）: 药品合计 **240 个工作日**: 文件验证 40 + 设施检查/采样 50 + 实验室分析 60 + 最终审核 68 + 批准会议/发证 22；客户原因延误不计入
- 注册有效期: **5 年**（NAFDAC 法规 Cap F33 + 注册指南 10.5，AI 联网待确认）；外国工厂 GMP 认证单独有效期（兽药口径 3 年，人药待确认）
- 再注册周期（续期指南 2025，AI 联网待确认）: 到期前**不迟于 6 个月**启动续期（须附 PSUR 交药物警戒部门审查）；逾期续期有附加费/罚金；续期处理时限 90 个工作日，成功后再获 5 年；NAFDAC 续期问询须 **45 个工作日**内答复否则自动关闭（新注册问询答复期限为 90 个工作日）
- 注意: 进口禁令清单 / NAFDAC Ceiling List / **5+5 清单**上的产品不受理续期（5+5 政策 = 要求外资厂 5 年内技术转让至尼日利亚本地生产）

## 7. 常见坑

- **现场审计卡死注册**: NAFDAC 来华 GMP 审计安排不了/不通过，注册就停摆（用户实战，已核实）
- 风险分级（2024 指南，待确认）: 中国工厂属「非 SRA 非 ML3」= **高风险** → 全量审评；含甘油/丙二醇/山梨醇等的**儿科糖浆类强制高风险**（DEG/EG 污染管控）
- 违反 Compliance Directive（CD）7 个工作日内须整改，否则申请可被取消（官方，待确认）
