复制即装 prompt · 草案
请帮我安装「作息管家」技能。这是一个作息记录、日程计划、AI 复盘闭环的作息管理技能。 请按以下步骤操作: 1. 在 https://github.com/FeatherHunter/SKILLS 仓库中找到「作息管家」目录(含 scripts/schedule_cli.py 的目录) 2. 把整个「作息管家」目录复制到你本机的技能目录: - Claude Code: ~/.claude/skills/作息管家 - opencode: ~/.config/opencode/skill/作息管家 3. 复制完成后告诉我「安装完成」,然后我会说「首次使用」,请你按首次使用流程帮我完成初始化
首次使用 · 6 步工作流
1
环境检测schedule_cli.py check —— OS / Python ≥3.7 / 目录可写 / DB 状态（检测全面，禁止误判"没装"）
2
路径确认展示 DB 基目录（env → D:/.db(win) → ~/.local/share/schedule-guardian/db(linux)），征求用户确认不静默
3
建库 + 初始化schedule_cli.py init —— 幂等（已有库跳过）
4
状态确认schedule_cli.py status —— 未初始化 / 库已建 / 就绪
5
渲染初始化报告 HTML6 步步骤条 + 环境信息 + 建库结果 + 下一步按钮（对标居家管家 first_use_wizard）
6
完成 / 失败重试提示说「作息管家 help」浏览功能；失败 → 错误回执（步骤/原因/建议）+ 一键重试

1复制即装 prompt 措辞：直接复制给 AI 就能装——「找到仓库目录 → 复制到技能目录 → 回复安装完成」三段式，对标备忘录，OK？
2首次使用 6 步：环境检测 → 路径确认 → 建库 → 状态确认 → 报告 → 完成。比居家管家少「建分类」（作息管家分类白名单随技能自带），比备忘录少飞书强引导（作息管家飞书可选），OK？
