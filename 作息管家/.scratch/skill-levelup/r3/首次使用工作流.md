## 核心原则（对标备忘录 9 步）

1. **引导式环境搭建**：检测 → 安装/配置 → 验证 → 下一步；每步必须给可执行指引，不允许只报告缺什么
2. **检测必须全面**：PATH 命令找不到 ≠ 没装。依次探测：① PATH 命令 → ② 常见自定义安装路径 → ③ 包管理器查询
3. **自动安装优先（Windows）**：用户同意后 `winget install Python.Python.3.12 --scope user`（作息管家需 ≥3.7）；不可用 → 手动指引 python.org
4. **PATH 刷新协议**：装完 Python 同会话 PATH 不刷新 → 用安装完整路径验证或 `cmd /c "python --version"`；禁止直接 `python --version` 判失败
5. **数据位置主动告知，不强制配置**：默认位置（Q6 链）客观陈述；用户无偏好 → 保持默认不打扰；主动要求 → 按用户路径设
6. **飞书强引导（2026-08-09 人类修正 · 原"可选"升级）**：飞书联动是作息管家核心能力之一（计划双向同步日历），**默认引导安装 + 强烈建议配置，说「配合飞书效果最好」**。只有用户明确拒绝才跳过，且报告页醒目标注「飞书同步不可用」；后续想用说「配置飞书」即可补装
7. **任何一步失败** → 报告页标 err/warn + 待办指引具体下一步，不静默跳过
8. **承诺↔兑现**：prompt 说的每项 → 报告页必须有对应物（检查项 / 待办 / 验证清单）

## 飞书强引导要点（对标备忘录 9 步 L354-406）

- **先说明为什么强烈建议配**：计划双向同步飞书日历 = 手机日历直接看到你的作息安排，配合飞书效果最好；**不配 = 飞书同步功能不可用**
- **检测**：`lark-cli` 是否存在（PATH → 常见安装路径 → npm 全局）；⚠️ 包名陷阱：官方包是 **`@larksuite/cli`**（bin 名 `lark-cli`），npm 上 `lark-cli` 是僵尸包，严禁指引安装
- **未安装 → 直接引导安装**（默认路径，不问"要不要装"）：Node ≥18（缺 → 自动安装 winget）→ `npm install -g @larksuite/cli` → `npx -y skills add https://open.feishu.cn --skill -y`
- **配置 app + 授权**：走**强制非阻塞模式**（`--no-wait --json` 拿 device_code → 发 QR/URL 给用户 → 用户"好了" → `poll_auth`），**禁止同步阻塞** `lark-cli config init --new` / `auth login`（会卡 timeout）
- **权限域**：`calendar`（计划写日历，必授）；需要时 `task`；一次授权
- **只有用户明确拒绝**（如「不用飞书」「跳过」）才标 warn 跳过 —— 但必须醒目告知功能残缺：飞书同步不可用

## 逐步流程（6 步）

### 1. 环境检测
- 检测：OS / Python 版本（≥3.7）/ 数据目录可写 / DB 状态
- 命令：`python ${SKILL_DIR}/scripts/schedule_cli.py check`（若已有该命令；无则 `init` 探测）
- 找不到可用 Python → 自动安装（winget，用户同意后）→ 失败 → 手动指引

### 2. 路径确认
- 展示 DB 基目录（Q6 链：`SKILLS_DB_PATH` env → `D:/.db`(win) → `~/.local/share/schedule-guardian/db`(linux)）
- **必须征求用户确认，不静默**（对标居家管家 SM8 第 2 步）

### 3. 建库 + 初始化
- 命令：`python ${SKILL_DIR}/scripts/schedule_cli.py init`（幂等：已有库 → 跳过；迁移逻辑在 init 内）

### 4. 状态确认
- 命令：`python ${SKILL_DIR}/scripts/schedule_cli.py status`（未初始化 / 库已建 / 就绪）

### 5. 渲染初始化报告 HTML
- 模板：`templates/开始使用/first_use_wizard.html`（对标居家管家：6 步步骤条 + 环境信息 + 建库结果 + 下一步按钮）
- 数据契约：`{"items":[{name,status(ok/warn/err),desc,action}], "todos":[{title,steps:[str]}], "verify":[str]}`（对标备忘录 init-report）

### 6. 完成
- 提示可说「作息管家 help」浏览功能 / 录第一条记录
- 失败 → `emit_error` 错误回执 HTML（步骤 / 原因 / 建议）+ 一键重试
