模板分合规则 · 你的问题

一个场景 · 一个唤醒词 · 一个模板

你的直觉是对的：呈现数据不同 → 就该不同模板。底层 start-end 计算可以复用，但那是「复用计算层」，不是「复用展示层」。

回答：是，需要不同模板

「复盘本周」和「复盘本月」虽然底层都走 start-end 区间聚合，但用户看到的信息构成不同（本周=7 维趋势+热力图+健康分均值；本月=月度聚合+环比+目标达成）——这就是两个不同的体验单元，按你定的「场景=独立呈现单元」原则，各配独立模板。复用的位置在计算层（区间聚合、7 维、健康分、环比这些函数），不在模板。

模板分合的判断标准
情况判断例子
信息构成相同，只换日期范围复用同一模板查今天/昨天/指定日期 → 都 record_day.html
信息构成不同（呈现的数据集变了）独立模板本周(趋势结构) vs 本月(环比目标) → 两模板
底层计算相同复用计算函数区间聚合/7维/健康分 → schedule_replay 计算层复用
落到复盘三件
复盘本周独立模板 · 周复盘.html计算复用
呈现
7 维趋势 + 热力图 + 健康分均值（异常日标注）+ 本周亮点/问题
底层
start-end 区间聚合（本周一~周日）→ 复用现有计算
复盘本月独立模板 · 月复盘.html计算复用
呈现
月度聚合 + 环比对比 + 目标达成 + 健康分趋势
底层
start-end 区间聚合（本月 1 日~末日）→ 复用现有计算
复盘区间（自由区间）按区间长度路由模板计算复用
呈现
~7 天 → 周模板；~30 天 → 月模板；其他 → 通用区间摘要
底层
同一 start-end 聚合，区间长度路由决定用哪个模板

一句话规则

一个场景 = 一个唤醒词 = 一个模板（呈现数据不同的场景，各自独立模板）
复用只发生在计算层（函数），不发生模板层（呈现不同）
自由区间场景按区间长度路由到最贴近的模板，不单独造第三套
