# 作息管家 (Schedule Guardian)

> 作息记录 · 日程计划 · AI 复盘闭环 —— 每晚「复盘今天 + 制定明天」的作息管理技能。
> 零基础用户入口。维护者指南见 `AGENTS.md`。

## 30 秒开始(安装)

把下面这段话**原样复制**发给你的人工智能(Claude / opencode / MiniMax Code / 其他支持技能的 AI),它就会帮你把技能装好:

```text
请帮我安装「作息管家」技能。这是一个作息记录、日程计划、AI 复盘闭环的作息管理技能。
请按以下步骤操作:
1. 在 https://github.com/FeatherHunter/SKILLS 仓库中找到「作息管家」目录(含 scripts/schedule_cli.py 的目录)
2. 把整个「作息管家」目录复制到你本机的技能目录:
   - Claude Code: ~/.claude/skills/作息管家
   - opencode: ~/.config/opencode/skill/作息管家
3. 复制完成后告诉我「安装完成」,然后我会说「首次使用」,请你按首次使用流程帮我完成初始化
```

安装完成后,对你的 AI 说 **「首次使用」**,它会引导你完成全部初始化——检测环境、初始化数据库、确认数据位置(全程零手动配置),并生成一份初始化报告。

## 这是什么

作息管家是「**记录 → 复盘 → 计划**」闭环的作息管理技能:

- **记录**:随时说一句,AI 帮你写成结构化作息记录(时间段 / 活动 / 分类),每记一笔立即返回**全天作息表** HTML
- **复盘**:每晚对**今天 / 本周 / 本月**复盘——计划 vs 实际对照、健康分、7 维趋势、异常缺口
- **计划**:制定**第二天**的日程,AI 多轮商量生成 24h 计划,贴合你的历史作息

它不是待办清单,不是日历 App,而是"记录过去、审视现在、安排明天"的私人作息管家。

**独有能力**(公开生态中独一无二):

| 能力 | 说明 |
|---|---|
| 记录即回作息表 | 每记一笔,返回全天作息时间轴结果 HTML(过去几小时推断 + 当前状态) |
| 复盘闭环 | 今日 / 周 / 月三层粒度,计划 vs 实际对照 + 健康分 + 趋势 + 异常识别 |
| 商量计划 | AI 多轮生成次日 24h 计划,时间轴 + 分类色带 + 与历史作息贴合提示 |
| 飞书日历联动 | 计划双向同步飞书日历(可选) |
| 数据本地 | 纯 Python 标准库 + SQLite,数据只存在你自己的设备上 |

## 数据与隐私

- **全部数据 = 1 个 SQLite 文件(`schedule_data.db`)**,存在你自己的设备上,不经过任何云服务器
- **默认位置**:Windows `D:\.db\schedule_data.db` · Linux `~/.local/share/schedule-guardian/db/schedule_data.db`
- **可选环境变量**:`SKILLS_DB_PATH`(数据库根目录,多技能共用);不设置时用默认位置,功能完全正常
- **飞书联动（强建议）**：配合飞书效果最好——计划双向同步飞书日历，手机日历直接看安排。需要 lark-cli 并授权；不配置则飞书同步不可用，其余功能不受影响（后续想说「配置飞书」补装）
