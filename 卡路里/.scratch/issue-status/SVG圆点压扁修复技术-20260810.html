SVG 圆点被压扁？
用 HTML 层覆盖修复

体重趋势迷你折线（Sparkline）首尾圆点的修复实录 —— 可复制的通用解法

现象

SVG 折线首尾的 <circle> 圆点，在手机上看成了被横向拉宽的扁椭圆，白描边左右厚、上下薄。

❌ 圆点被压扁：高度方向压缩，宽高比 ≠ 1:1

根因：preserveAspectRatio="none"

为了让折线铺满卡片宽度，SVG 常用 width:100% + preserveAspectRatio="none"——意思是不保持纵横比，自由拉伸去适配容器。问题是它会把 SVG 里的所有图形一起拉伸，包括圆形：

viewBox 300 × 56 实际容器 327 × 56 横向放大 1.09 × circle 跟着变椭圆

圆点不是「自己」变形的，而是被整个 SVG 坐标系非等比缩放拖累的。折线无所谓（线拉伸看不出来），圆形受不了（形状可感知）。

解法：圆点 HTML 化

把圆点从 SVG 里拿出来，改成 HTML 层：一个绝对定位的 div，盖在折线两端。div 是页面级元素，不受 SVG 坐标系缩放影响，永远正圆：

// 1. SVG 只画折线（去掉 circle），容器 position:relative
<div style="position:relative">
  <svg viewBox="0 0 300 56"
       preserveAspectRatio="none"
       style="width:100%;height:56px;display:block">
    <polyline points="..." stroke="#0071e3" stroke-width="2"/>
  </svg>

// 2. 圆点用 HTML div：宽高相等 + 圆角 50% = 任何屏幕都精确正圆
<div style="position:absolute;
  left:2%;  top:12.5%;          ← SVG 坐标换算成百分比
  width:9px; height:9px;
  border-radius:50%;
  background:#0071e3;
  border:2px solid #fff;         ← 白描边（Apple 数据点风）
  transform:translate(-50%,-50%); ← 以圆心锚定
  box-shadow:0 1px 2px rgba(0,0,0,.15)"></div>
</div>

关键就 3 步：① 圆点移出 SVG；② 位置用百分比对齐折线端点；③ translate(-50%,-50%) 让圆心中点锚定。白描边 + 轻阴影是顺手加的视觉增强。

位置换算：SVG 坐标 → 百分比

SVG 内部是 viewBox 坐标系（0~300 × 0~56），HTML 层是容器百分比。换算公式（两端留了 6px 内边距）：

// x: viewBox 宽 300 → left 百分比
left%  = x / 300 * 100        // 端点 x=6 → 2%；x=294 → 98%

// y: viewBox 高 56 == CSS 固定高度 56px → top 百分比
top%   = y / 56  * 100        // 高不变，直接比例

// 圆点宽 9px + translate(-50%,-50%) → 圆心精确落在折线端点上

CSS 高度固定（56px）时 y 换算零误差；若高度也自适应，需用 aspect-ratio 或 ResizeObserver 再算一次。

验证（我实际做的双重检查）

方法结果
DOM 测量 getBoundingClientRect()w = 9.00px, h = 9.00px, ratio = 1.000 ✓
像素级分析（PIL 量圆点像素边界）3× DPI 截图上蓝/绿点均 14×14px，ratio = 1.000 ✓
视觉模型复核（375px 手机截图）白描边均匀、无裁剪、颜色与折线端点一一对应 ✓

顺带一提：视觉模型两次把正圆误判成「扁椭圆」——所以小图形设计别只信 AI 看图，用 DOM/像素测量做 ground truth。

完整最小 Demo（可复制自测）

<!DOCTYPE html>
<html>
<body style="background:#f5f5f7;font-family:system-ui;padding:40px">
  <div style="background:#fff;border-radius:16px;padding:20px;max-width:360px">
    <div style="position:relative">
      <svg viewBox="0 0 300 56" preserveAspectRatio="none"
           style="width:100%;height:56px;display:block">
        <polyline points="6,8 100,20 200,35 294,48"
                  fill="none" stroke="#0071e3" stroke-width="2"
                  stroke-linecap="round"/>
      </svg>
      <div style="position:absolute;left:2%;top:14.3%;width:9px;height:9px;
                  border-radius:50%;background:#0071e3;border:2px solid #fff;
                  transform:translate(-50%,-50%)"></div>
      <div style="position:absolute;left:98%;top:85.7%;width:9px;height:9px;
                  border-radius:50%;background:#34c759;border:2px solid #fff;
                  transform:translate(-50%,-50%)"></div>
    </div>
    <div style="display:flex;justify-content:space-between;
                font-size:12px;color:#6e6e73;margin-top:8px">
      <span>起点</span><span>终点</span>
    </div>
  </div>
</body>
</html>

把上面代码存成 demo.html 双击打开，拖窄浏览器窗口，圆点始终是正圆。

为什么不用其他方案

方案为什么否决
改 viewBox 比例 = 容器比例容器宽度随设备变（375/390/414/768…），写死即失效
SVG 内画椭圆反向补偿每次渲染都要按实际宽高比算 rx/ry，脆弱难维护
去掉 preserveAspectRatio="none"折线会按比例缩放留白，铺不满卡片宽度
HTML 层圆点（采用）零缩放耦合：折线随便拉伸，圆点永远正圆；还能用 CSS 加白边/阴影/动画

一句话总结

✓ SVG 的 preserveAspectRatio="none" 会把所有图形非等比拉伸 —— 圆点别画在 SVG 里，用 HTML 层盖上去，形状就脱离坐标系缩放了。
