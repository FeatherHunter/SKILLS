# Triage Notes · KPI grid 在手机上 2x2 排列

> *This was generated by AI during triage.*

## What's requested

用户在 2026-07-30 第二轮反馈中提出:

> 手机版本顶部的四个模块"当前体重、24天变化、日均变化、当前BMI"在手机时应该是四宫格效果。就是第一排是前两个 第二排是后两个,这四个控件的宽高一致。在手机浏览器是这样,电脑的还是原先效果。

## What's established

### 现状(`templates/weight_history.html` line 25-26, 67, 88)
```css
/* 主样式:4 列 */
.kpi-grid { display:grid; grid-template-columns:repeat(4,1fr); gap:12px; margin-bottom:20px; }

/* @media (max-width:640px):2 列 */
.kpi-grid { grid-template-columns:repeat(2,1fr); gap:10px; }

/* @media (max-width:400px):1 列 */
.kpi-grid { grid-template-columns:1fr; }
```

### 实测 Playwright(2026-07-30)

| viewport | gridTemplateColumns | 实测效果 |
|---|---|---|
| iPhone SE 375×667 | `359px` (1 列) | 4 行堆叠 |
| iPhone XR 414×896 | `194px 194px` (2 列) | 2x2 ✓ |
| iPhone 15 393×852 | `377px` (1 列) | 4 行堆叠 |

### 根因

`@media (max-width:400px)` 把 375px(iPhone SE)、393px(iPhone 15) 等主流手机宽度都打到 1 列堆叠模式,用户看到的就是"4 个 KPI 排成竖排",而非预期的 2x2。

## Proposed fix

**移除 `<400px` 强制 1 列的规则**,让所有 mobile 设备(≤640px)都保持 2x2:

```css
/* 删 line 86-88 的 @media (max-width:400px) 块 */
```

或保留 `@media (max-width:400px)` 但不改 column(仅调小内部字号):

```css
@media (max-width:400px) {
  .kpi-grid { grid-template-columns:repeat(2,1fr); }  /* 保持 2x2 */
  .kpi .value { font-size:15px; }  /* 微调字号适配更窄屏 */
}
```

### 设计权衡

| 选项 | 优 | 劣 |
|---|---|---|
| 删 `<400px` 整块 | 极简 | 小屏(≤350px)2 列会很挤 |
| 改 `<400px` 保留 2 列 | 兼容小屏 | 字号要再小 |

**推荐**:删 `<400px` 块。当前主流手机宽度最小 360px(iPhone SE 一代),2 列每列宽 170px,装下 "86.9 kg" 没问题。
