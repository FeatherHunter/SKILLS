# 卡路里 · Domain Glossary

> CONTEXT.md · 首次创建 · 2026-08-13 · ADR-0013（热量缺口统一约定）

卡路里技能的领域术语词典。不写实现细节，只固化"概念是什么 / 与其他概念的关系"。

---

## 核心概念

### 热量缺口（Calorie Deficit）

热量缺口 = 消耗 − 摄入，**正值 = 缺口 = 减重潜力**（消耗 > 摄入）；负值 = 盈余（摄入 > 消耗，增重方向）。

- 消耗 = TDEE（档案 BMR × 活动系数）+ 当日运动消耗
- 摄入 = 当日食物热量合计（不含饮水记录）
- 日常分析（series 系：组合分析/健康报告/趋势/诊断/预测）默认使用本口径

_Avoid_: 用「摄入 − 消耗」表示缺口、把负值当缺口（series.py 旧公式语义，ADR-0013 已废弃）；与「基础代谢缺口」混用同一名称

### 基础代谢缺口（BMR Deficit）

基础代谢缺口 = BMR + 运动消耗 − 摄入，正值 = 缺口。

与「热量缺口」的区别：基准用 BMR（不含活动系数折算的日常活动量），数值系统性小于 TDEE 口径，两者不可直接比较。

用于基础代谢口径的分析（diet_deficit_analysis / 健康仪表盘 / 主页缺口公式条）。

_Avoid_: 称其为「热量缺口」；与 TDEE 口径数值混比

### TDEE（每日总消耗）

TDEE = 档案 BMR × 活动系数（身高/体重/年龄/性别/活动量）。热量缺口（日常分析）的基准口径。

### BMR（基础代谢率）

BMR = 体重 × 24 × 活动系数（diet.py 口径）。基础代谢缺口的基准口径。

### TEF（食物热效应）

食物热效应 ≈ 摄入的 10%。热量缺口统一约定**不默认扣除 TEF**（legacy 渲染器曾以「TDEE−300」近似，ADR-0013 已归一），如需可作为可选参数。

_Avoid_: 把「TDEE−300」当 TDEE 口径使用
