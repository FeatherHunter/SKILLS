## 格式约定(2026-08-02 对抗式审查沉淀)

1. **prompt 第一性原理**:prompt = 用户对 AI 说的话(意图 + 呈现数据承诺);**AI 流程由 SKILL.md 唤醒词底层设计决定**,prompt 不写流程描述词(「请先查…」「第一步」等)
2. 信息缺失才补问(记/补记类);改/删类用户没说清时「先列最近记录让用户选 → 快照确认 → 操作 → 回执」(交互规则落 SKILL.md §饮食)
3. 无技术词泄露(JSON/CLI/id 等);「JSONL 文件」→「食品数据文件(每行一条)」
4. 填空格式「字段名(单位):____」;收尾「完成后给 1 句话总结,不需要过多文字解释。」
5. 承诺必须与 HTML 呈现数据对齐(如「每杯时间」→ today_water cups;「分类」→ food_search .cat)
