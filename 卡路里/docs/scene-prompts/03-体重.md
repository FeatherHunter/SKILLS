## 格式约定(2026-08-02 讨论沉淀)

1. **prompt = 用户对 AI 说的话(意图 + 呈现数据承诺)**;AI 流程(交互规则/算法口径)由 SKILL.md 唤醒词底层设计决定,不写进 prompt
2. 场景名全角括号(与权威清单 `.scratch/scene-index-recovered.md` §3 一致),如 记体重（含备注）
3. 「完成后给 1 句话总结」并入 body 段,不放最后
4. 对比 18 场景名以「对比体重：」前缀 + 后缀区分(主名 对比体重 ≤12 字,后缀 ≤18 字)

## SKILL.md 规则清单(唤醒词底层设计 · 2026-08-02 · 抽离自 prompt)

| 场景 | 规则 |
|---|---|
| 补录体重 | 目标日已有记录 → 提示冲突(已有值 vs 新值),询问覆盖/保留后写入 |
| 改体重记录 | 用户未指明记录 → 列出最近候选(日期/体重/备注)供选择;确认后改 |
| 删体重记录 | 用户未指明记录 → 列候选;**删除前快照确认**;确认后删除 |
| 删某日/批量删 | 删除前告知命中条数 → 用户确认 → 删除 |
| 对比：本周 vs 上周 | 每段记录数 ≥3 才显示对比,否则「样本不足」提示 |
| 对比：今天 vs N 前 | 同期对比 ±3 天容差;未命中 → 容差命中说明(实际取到哪条/无数据) |
| 对比：平台期首日 | 平台期 = 至少连续 14 天波动 ≤ ±0.5kg;取最近一次;统计第几次 + 历史平均突破耗时 |
| 对比：减重 5/10kg | 里程碑 = 从历史最高起累计减重 N kg 的第一个达标日 |
| 对比：入夏/入冬最低 | 入夏 = 当年 6/1–8/31;入冬 = 12/1–次年 2/28(最近一个冬天) |
| 对比：运动多 vs 少 | 极端月 = 运动总量最高/最低的自然月;睡眠数据缺失 → 标注缺失(只读外部技能) |
