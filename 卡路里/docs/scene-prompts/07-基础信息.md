## 格式约定(2026-08-02 讨论沉淀)

1. 采访式引导 = 设置档案 默认交互:用户没说全时逐项问 + 按日常情况推荐活动量(规则已落地 SKILL.md §基础信息)
2. 改档案支持多字段,「字段名(新值):____」一行一条
3. 「完成后给 1 句话总结」并入 body 段,不放最后

## 1. 设置档案(`profile_setup`)

- 分类:基础信息 · 子功能:设置资料 · 类型:receipt
- 呈现数据:身高/年龄/性别/活动量 + 自动推荐活动量 + 设置时间
- data_source:`python scripts/render_crud_receipt.py --live-profile-set --age <A> --gender <G> --height <H> --activity <L> --chain "1.解析→2.写库→3.回执"`(写库 + 回执 HTML;--chain 强制)

```请你加载技能 卡路里,执行唤醒词「设置档案」。

我想设置基础档案(身高/年龄/性别/活动量)。如果我没说全,请一项一项问我,并根据我的日常情况推荐合适的活动量。交付 HTML 时,文字只回复精简而全面概括的信息,文字不允许超过三句话。

我的身高(cm):____
年龄:____
性别(男/女):____
日常活动情况(选填,用于推荐活动量):____```

## 2. 设活动量(`profile_set_activity`)

- 分类:基础信息 · 子功能:设置资料 · 类型:receipt
- 呈现数据:活动等级 + 影响(TDEE 系数)
- data_source:`python scripts/render_crud_receipt.py --live-profile-activity <level> --chain "1.解析→2.写库→3.回执"`(--chain 强制)

```请你加载技能 卡路里,执行唤醒词「设活动量」。

我要单独设置活动量(久坐/轻度/中度/活跃/高度活跃)。交付 HTML 时,文字只回复精简而全面概括的信息,文字不允许超过三句话。

我的活动量(久坐/轻度/中度/活跃/高度活跃):____```

## 3. 改档案(`profile_update`)

- 分类:基础信息 · 子功能:改资料 · 类型:receipt
- 呈现数据:改前/改后 + 影响提示
- data_source:`python scripts/render_crud_receipt.py --live-profile-update --field <X> --value <Y> --chain "1.解析→2.写库→3.回执"`(--chain 强制)

```请你加载技能 卡路里,执行唤醒词「改档案」。

我要改档案里的字段(身高/年龄/性别/活动量/备注)。改之前请先确认我原来的值。交付 HTML 时,文字只回复精简而全面概括的信息,文字不允许超过三句话。

我要改的字段(允许一行一条,可改多个):
身高(新值):____
年龄(新值):____
性别(新值):____
活动量(新值):____
备注(新值):____```

## 4. 查档案(`profile_view`)

- 分类:基础信息 · 子功能:看档案 · 类型:result
- 呈现数据:档案字段(含活动量)+ 最新体重 + BMI/BMR/TDEE(含系数说明)
- data_source:`python scripts/render_crud_view.py --entity profile --chain "1.识别→2.读DB→3.算TDEE"`(--chain 强制)

```请你加载技能 卡路里,执行唤醒词「查档案」。

我想看自己的完整档案。交付 HTML 时,文字只回复精简而全面概括的信息,文字不允许超过三句话。```
