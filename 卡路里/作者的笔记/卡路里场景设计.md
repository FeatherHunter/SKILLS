## 1. 体重（60 场景）

### W1 量体重（6）

#### 1. 记体重
- **描述**：用户当前称了体重，立刻记录到今日。
- **呈现数据**：当日体重 / 当日 BMI / 距上次体重（kg + 天数）/ 距今日目标（kg）/ 一句话总结

#### 2. 记体重（含备注）
- **描述**：在记体重基础上添加备注（如"晨起空腹""运动后"）。
- **呈现数据**：记体重全部 + 备注内容 + 备注分类标签（晨起/睡前/运动后/餐前/餐后）

#### 3. 补录体重
- **描述**：补录昨天或前几天未记录的体重。
- **呈现数据**：补录日期 / 补录体重 / 补录标识 / 冲突处理（跳过/覆盖/新建）/ 一句话总结

#### 4. 补录历史体重
- **描述**：补录多天前的体重记录。
- **呈现数据**：补录日期 / 补录体重 / 距今天数 / 冲突处理 / 一句话总结

#### 5. 批量补录体重
- **描述**：一次性补录多天体重。
- **呈现数据**：写入/跳过/失败条数 / 失败明细（日期+原因）/ 一句话总结

#### 6. 看今日体重
- **描述**：仅查看今日体重，不记录。
- **呈现数据**：今日体重 / 距上次记录 / 提示"今日未称体重"/ 一句话状态

### W2 改体重记录（5）

#### 1. 改体重记录
- **描述**：修改某条体重记录的数值或备注。
- **呈现数据**：改前/改后 / 影响字段 / 一句话总结

#### 2. 改某日体重
- **描述**：按日期定位修改那天的体重。
- **呈现数据**：命中条数 / 命中 ID / 改前/改后 / 一句话总结

#### 3. 删体重记录
- **描述**：删除某条体重记录。
- **呈现数据**：删除前快照 / 确认回执 / 一句话总结

#### 4. 删某日体重
- **描述**：删除某天全部体重记录。
- **呈现数据**：删除条数 / 删除日期 / 删除前快照汇总 / 一句话总结

#### 5. 批量删体重
- **描述**：按日期范围批量删除。
- **呈现数据**：时间范围 / 删除条数 / 确认回执 / 一句话总结

- **呈现数据**：本周体重全部 / 与本周对比 Δkg

##### 3. 看本月体重
- **描述**：本月（自然月）每天体重明细表。
- **呈现数据**：表格 / 月均值 / 月净变化 / 一句话总结

##### 4. 看上月体重
- **描述**：上月（自然月）每天体重明细表。
- **呈现数据**：本月体重全部 / 与本月对比

##### 5. 看最近 7 天体重

#### 看曲线（10）

##### 3. 看体重曲线（带里程碑）
- **描述**：折线 + 减重 5/10kg 里程碑标记。
- **呈现数据**：看体重曲线全部 / 里程碑标记（5kg/10kg）/ 达成日期 / 距下一个里程碑

##### 4. 看体重曲线（带异常点）
- **描述**：折线 + σ 异常点红圈。
- **呈现数据**：看体重曲线全部 / 异常点列表（日期/值/偏离 σ 倍数）/ 异常可能原因

##### 5. 看本月体重曲线
- **描述**：自然月折线图。
- **呈现数据**：看体重曲线全部 / 月度跨度

##### 6. 看上月体重曲线
- **描述**：上月折线图。
- **呈现数据**：看体重曲线全部 / 与本月对比

##### 7. 看最近 90 天体重曲线
- **描述**：90 天滚动折线。
- **呈现数据**：看体重曲线全部 / 降采样提示（每 3 天一个点）

##### 8. 看最近 180 天体重曲线
- **描述**：180 天滚动折线。
- **呈现数据**：看体重曲线全部 / 降采样（每周一个点）

##### 9. 看最近 365 天体重曲线
- **描述**：365 天滚动折线。
- **呈现数据**：看体重曲线全部 / 降采样（每月一个点）

##### 10. 看某段时间体重曲线
- **描述**：用户给起止日期。
- **呈现数据**：看体重曲线全部 / 跨度自适应降采样

#### 看稳不稳（7）

##### 1. 看体重稳不稳
- **描述**：默认 30 天波动分析。
- **呈现数据**：波动图（折线+σ 区间带）/ KPI（日均波动 g/标准差/异常次数）/ 稳定性判断 / 一句话总结

##### 2. 看体重波动分析
- **描述**：v2 风格 dashboard。
- **呈现数据**：3 张 KPI（诊断/趋势/早警告）/ Canvas 主图（±σ 带+目标线）/ 异常列表 / 基线 toggle

##### 3. 看体重是否稳定
- **描述**：v2 别名。
- **呈现数据**：同看体重波动分析

##### 4. 看本月波动
- **描述**：自然月波动分析。
- **呈现数据**：看体重稳不稳全部

##### 5. 看最近 90 天波动
- **描述**：90 天波动分析。
- **呈现数据**：看体重稳不稳全部 + 降采样

##### 6. 看最近 180 天波动
- **描述**：180 天波动分析。
- **呈现数据**：看体重稳不稳全部 + 降采样

##### 7. 看波动异常点
- **描述**：仅显示异常点详情。
- **呈现数据**：异常点列表（日期/值/偏离 σ）/ 异常可能原因 / 一句话总结

#### 看备注（1）

##### 1. 看「有备注」的体重记录
- **描述**：列出所有含 note 的体重记录。
- **呈现数据**：表（日期/体重/备注/vs 前后日均值）/ 备注分类分布 / 一句话总结

#### vs 极值 / 里程碑（6）

##### 1. 对比体重：当前 vs 历史最低
- **描述**：当前 vs 历史最低那天的对比。
- **呈现数据**：当前/历史最低日期+体重 / Δkg / 历史最低至今天数 / 距最低日每日均值 / 一句话总结

##### 2. 对比体重：当前 vs 历史最高
- **描述**：当前 vs 历史最高对比。
- **呈现数据**：当前/历史最高日期+体重 / 已下降 Δkg / 历史最高至今天数 / 平均减重速率 / 一句话总结

##### 3. 对比体重：减重 5kg 那天 vs 今天
- **描述**：反查里程碑。
- **呈现数据**：当前/减重 5kg 起始日期+体重 / 用时天数 / 平均速率 / 中间过程轨迹（每 30 天采样）/ 是否经历过回弹 / 一句话总结

##### 4. 对比体重：减重 10kg 那天 vs 今天
- **描述**：反查减重 10kg 里程碑。
- **呈现数据**：同减重 5kg

##### 5. 对比体重：当前 vs 入夏最低
- **描述**：当前 vs 今年入夏（6/1-8/31）最低。
- **呈现数据**：当前/入夏最低日期+体重 / Δkg / 入夏至今天数 / 当年 vs 历年入夏最低均值 Δkg / 一句话总结

##### 6. 对比体重：当前 vs 入冬最低
- **描述**：当前 vs 入冬（12/1-次年 2/28）最低。
- **呈现数据**：同当前 vs 入夏最低

### W4 体重目标（13）

#### 1. 定体重目标
- **描述**：设置目标 kg + 截止日期。
- **呈现数据**：目标值/截止日期 / 距今 Δkg / 建议速率 g/天 / 一句话总结

#### 2. 定体重目标（自动算截止）
- **描述**：按用户期望速率推算截止。
- **呈现数据**：目标值 / 推算截止 / 校验速率合理性（>1kg/周警告）/ 一句话总结

#### 3. 定体重目标（含起始日）
- **描述**：完整 setup。
- **呈现数据**：起始日/目标值/截止 / 用时天数/速率 / 一句话总结

#### 4. 定体重目标（不指定截止）
- **描述**：仅设目标值。
- **呈现数据**：目标值 / 预计完成时间 / 一句话总结

#### 5. 定体重目标（联动营养）
- **描述**：设体重目标时联动更新营养目标。
- **呈现数据**：体重目标+推荐营养目标 / 联动提示 / 一句话总结

#### 6. 看体重目标进度
- **描述**：当前体重目标的完成度。
- **呈现数据**：当前/目标/Δkg / 完成 % / 一句话状态

#### 7. 看体重目标进度（含预测）
- **描述**：含预计达成日期。
- **呈现数据**：看体重目标进度全部 / 预计达成日期 / 提前或落后天数 / 一句话总结

#### 8. 看体重目标 vs 实际进度
- **描述**：预期 vs 实际速率对比。
- **呈现数据**：预期速率/实际速率 / 偏差 % / 是否需要调整建议 / 一句话总结

#### 9. 看历史完成的目标
- **描述**：历史已完成的所有体重目标。
- **呈现数据**：列表（完成日期/起始/目标/用时）/ 成功率 / 一句话总结

#### 10. 改体重目标
- **描述**：修改目标值/截止。
- **呈现数据**：改前/改后 / 影响预估 / 一句话总结

#### 11. 改目标截止日期
- **描述**：仅改截止日期。
- **呈现数据**：改前截止/改后截止 / 影响预估 / 一句话总结

#### 12. 暂停体重目标
- **描述**：临时冻结目标。
- **呈现数据**：暂停状态 / 提示"暂停后首页 KPI 隐藏目标" / 一句话总结

#### 13. 重启体重目标
- **描述**：解冻目标。
- **呈现数据**：重启状态 / 当前进度 / 一句话总结

### W5 体重复盘（8）

- **呈现数据**：本周复盘全部 + 月度趋势图 + 年度专属

#### 7. 体重复盘（自定义时间）

- **呈现数据**：本周复盘全部 + 自定义区间

#### 8. 看里程碑回溯

- **呈现数据**：表（里程碑名/达成日期/当日体重/用时）/ 总里程碑数 / 一句话总结

## 2. 饮食（含食品库）（50 场景）
