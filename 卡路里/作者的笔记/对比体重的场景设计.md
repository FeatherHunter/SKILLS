# 对比体重的场景设计

> 2026-07-30 · 第一性原理版本（AI 已完成对抗式审查 + 融合）
>
> 每条场景 = 名称 + 描述 + 呈现数据。原则：每个数据点必须回答用户的真实减肥决策问题，否则删除。

## A. 时间维度

| # | 场景名 | 描述 | 呈现数据 |
|---|---|---|---|
| A1 | 对比体重：最近 30 天 vs 之前 30 天 | 默认对半切 | 两段各均值 / 起始 / 终止 / 段内变化 / 段内波动 / Δkg / Δ方向 / 速率差 g/天 / 速度判断文字（快了/慢了/持平） |
| A2 | 对比体重：自定义两段时间 | 用户给两段任意起止日期 | 同 A1 |
| A3 | 对比体重：本周 vs 上周 | 自然周对齐 | 同 A1 + 每段记录数（≥3 条才显示对比，否则提示"样本不足"） |
| A4 | 对比体重：本月 vs 上月 | 自然月对齐 | 同 A1 |
| A5 | 对比体重：近 N 天 vs 上一个 N 天 | 用户给 N，滚动窗口 | 同 A1，N 由用户传 |
| A6 | 对比体重：今天 vs 一年前今天 | 同期对比（±3 天容差） | 当前体重 / 一年前同日体重 / Δkg / Δ方向 / 一年 Δ / 容差命中说明（"一年前同日无记录，使用 7/28 那条"）/ 一年内区间段均值 |
| A7 | 对比体重：今天 vs 半年前今天 | 同期对比（±3 天容差） | 同 A6 |
| A8 | 对比体重：今天 vs 三月前今天 | 同期对比（±3 天容差） | 同 A6 |

## B. 对象维度

| # | 场景名 | 描述 | 呈现数据 |
|---|---|---|---|
| B1 | 对比体重：当前 vs 目标体重 | 距目标差值 | 当前 / 目标 / Δkg / 已完成 % / 预计达成日期（按当前速率推算）/ 当前 BMI / 目标 BMI / 是否达标判断 |
| B2 | 对比体重：当前 vs 历史最低 | 自动定位 | 当前 / 历史最低日期 + 体重 / 距最低 Δkg / 历史最低至今天数 / 距最低日每日均值 |
| B3 | 对比体重：当前 vs 历史最高 | 自动定位 | 当前 / 历史最高日期 + 体重 / 已下降 Δkg / 历史最高至今天数 / 平均减重速率 g/天 |
| B4 | 对比体重：当前 vs 减重 5kg 那一天 | 反查里程碑 | 当前 / 减重 5kg 起始日期 + 体重 / 用时天数 / 平均速率 g/天 / 中间过程轨迹（每 30 天一个采样点）/ 是否经历过回弹 |
| B5 | 对比体重：当前 vs 减重 10kg 那一天 | 反查里程碑 | 同 B4 |
| B6 | 对比体重：当前 vs 入夏最低 | 季节定位（6/1~8/31 最低） | 当前 / 入夏最低日期 + 体重 / Δkg / 入夏至今天数 / 当年 vs 历年入夏最低均值 Δkg |
| B7 | 对比体重：当前 vs 入冬最低 | 季节定位（12/1~次年 2/28 最低） | 同 B6 |
| B8 | 对比体重：当前 vs 平台期首日 | 自动识别平台期（≥14 天波动 ≤±0.5kg） | 当前 / 平台期首日 + 体重 / 平台期天数 / 突破后 Δkg / 这是第几次平台期 / 历史平台期平均突破耗时 |

## C. 行为关联

| # | 场景名 | 描述 | 呈现数据 |
|---|---|---|---|
| C1 | 对比体重：过去 N 天体重与每日运动消耗 | 双轴折线，N 默认 30（允许 7/15/30/60/90/180/365） | 双轴折线图（体重 + 当日运动 kcal）/ 时间段净变化 / 运动日均 / 相关性文字 / 运动日 vs 休息日体重分层均值 |
| C2 | 对比体重：过去 N 天体重与每日摄入热量 | 双轴折线，N 默认 30（允许 7/15/30/60/90/180/365） | 双轴折线图（体重 + 当日摄入 kcal）/ 时间段净变化 / 摄入日均 / 相关性文字 / 高摄入日（>目标 110%）标记 + 这些日的次日体重反应 |
| C3 | 对比体重：过去 N 天体重与每日蛋白摄入 | 双轴折线，N 默认 30（允许 7/15/30/60/90/180/365） | 双轴折线图（体重 + 当日蛋白 g）/ 时间段净变化 / 蛋白日均 / 相关性文字 / 每 kg 体重蛋白 g 数 / 是否达标（推荐 ≥1.6g/kg） |
| C4 | 对比体重：过去 N 天体重与每日热量缺口 | 双轴折线，N 默认 30（允许 7/15/30/60/90/180/365） | 双轴折线图（体重 + 当日缺口 kcal）/ 时间段净变化 / 缺口日均 / 相关性文字 / 缺口类型分层（减脂缺口 < -300 vs 维持缺口 ±100）/ 不同缺口的体重反应 |
| C5 | 对比体重：运动多 vs 运动少的两个月 | 自动选两个极端月对比 | 运动最高月 vs 最低月 / 各自体重均值 / 各自段内变化 / 各自运动总量 / Δkg / 速率差 / 两个月各自的摄入 kcal + 睡眠时长（协变量，控制单一变量归因） |
