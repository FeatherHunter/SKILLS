👁️ 图眼 — 给无视觉模型装眼睛

把图片变成高保真文本，让 deepseek 这类纯文本模型「看得见」。粗看 / 精扫 / 读图 / 问图 / 审图，五档能力一页掌握。图眼是纯眼睛——调用者（deepseek 等 agent）自己就是大脑，不存在 API key。

场景操作台

看图粗看 · 这张图是什么
单次整体描述，适合快速理解。支持本地图片 / 截图 / 网页图片 URL。
精扫仔细看 · 不放过细节
3×3 切片 + 放大 + 逐片审计，产出分区域细节文档。截图审计、小字、手写、UI 还原用它。
读图提取图里的文字
OCR 专项提取全部文字，逐字输出。发票金额、便签手写、截图正文用它。
问图看图 + 提问 · 兜底大脑回答
精扫细节文档喂给内置兜底大脑 MiniMax-M3 作答（仅无大脑的 CLI 环境）。若你是 deepseek 等 agent 调用者，直接用「精扫/读图」拿文本自己推理即可，无需本场景。信息不足会如实说，不编造。
审图审问式核图 · 收敛细节
大脑读细节文档后生成追问，眼睛定向回答，多轮收敛。医学影像、图纸复核、证据保全用这个。

常用命令

cd D:\2Study\StudyNotes\SKILLS\图眼
python scripts/eye.py look  --image <图片>                       # 粗看
python scripts/eye.py scan  --image <图片> --out doc.md           # 精扫
python scripts/eye.py ocr   --image <图片>                        # 读图
python scripts/eye.py ask   --image <图片> --question "问题"      # 问图
python scripts/eye.py audit --image <图片> --rounds 2 --out a.md  # 审图
python scripts/eye.py --output json ask --image <图片> --question "?"  # JSON 契约

输入支持:本地路径 / http(s) URL / mmx file-id。图眼是纯眼睛:deepseek 等 agent 调用者自己就是大脑,直接消费文本推理;ask/audit 的兜底大脑 MiniMax-M3 仅服务无大脑 CLI 环境。
