## Commit 格式约束(本仓库硬规则)

来源:历史 commit 模式 + `[私有大厨] F 任务说明:5b4cb04 commit 信息错位(零风险方案)` 先例。

### 标准格式

```
[<skill 中文名>] <主题> · <细节(可选)>
```

或变体(类型词必须中文,emoji 可选):

```
<类型>: <skill 中文名> <主题> · <细节>
```

```
<emoji><类型>: <skill 中文名> <主题> · <细节>
```

### 合法类型词(中文)

| 类型 | 语义 | emoji(可选) |
|---|---|---|
| 功能 | 新增功能 | ✨ |
| 修复 | bug 修复 | 🐛 |
| 文档 | 文档变更 | 📚 |
| 杂务 | 清理/重命名/重构 | 🧹 |
| 测试 | 测试相关 | 🧪 |
| 性能 | 性能优化 | ⚡ |
| 样式 | 格式/样式(不改语义) | 💄 |

### 禁用

- ❌ 英文类型前缀:`fix:` / `docs:` / `feat:` / `chore:` / `refactor:` / `test:`
- ❌ 英文括号类型:`fix(...)` / `docs(...)` / `feat(...)` / `chore(...)`
- ❌ 错别字(参考 `5b4cb04 [私大有厨] ...` 被 `6387a11` 修正的先例)
