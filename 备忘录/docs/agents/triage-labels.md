# Triage 标签

技能以五个标准 triage 角色进行表述。本文件把这些角色映射到本仓库问题追踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们追踪器中的标签      | 含义                                   |
| --------------------------- | ----------------------- | -------------------------------------- |
| `needs-triage`              | `needs-triage`          | 维护者需要评估此问题                    |
| `needs-info`                | `needs-info`            | 等待提交者补充更多信息                  |
| `ready-for-agent`           | `ready-for-agent`       | 已完整规格化，可供 AFK agent 执行       |
| `ready-for-human`           | `ready-for-human`       | 需要人工实施                            |
| `wontfix`                   | `wontfix`               | 不会处理                                |

当某技能提及某角色（例如「应用 AFK-ready triage 标签」）时，使用本表中对应行的标签字符串。

如需修改，编辑右列以匹配你实际使用的词汇。
