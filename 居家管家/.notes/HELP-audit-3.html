3. 你贴的代码为啥看起来错?

可能原因 1:Chrome DevTools 自动转义显示

Chrome DevTools "Elements" 面板会把 & 显示为 &(不带分号)——它是 HTML entity,但浏览器渲染时人眼看到一个"裸" &。

可能原因 2:你的浏览器实际"破"

测试方法:打开 DevTools → Console → 执行 esc('<script>alert(1)</script>') 应当返回 '&lt;script&gt;alert(1)&lt;/script&gt;'。

可能原因 3:某个扩展/缓存错误

Ctrl+Shift+R 强制刷新,清浏览器缓存。

4. 我看到 2 个真问题

问题 A · 本地 esc/arr 重复定义P2

help_center.html 末尾有自己的 function esc() 和 function arr()。renderer 注入 shared.js 后,两个同名函数共存——后者覆盖前者(后定义的赢)。

当前 work(实现一致),但违反 DRY(R9 单一权威源)。

修复:删除 help_center.html 末尾的本地 esc/arr(只用 shared 的)。

问题 B · 我没在 IIFE 里用 shared 的 yes/validate/valP2

shared 有 5 个函数,help_center 只用 2 个(esc/arr)。yes/validate/val 是死代码在这个文件里。

说明:不是 bug,是预期(其他模板用);保留 shared JS 完整注入。
