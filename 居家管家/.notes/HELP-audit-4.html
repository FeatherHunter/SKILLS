你贴的代码为什么"看起来错"

你看到的:

function esc(s){return String(s??'').replace(/[&<>"']/g,c=>(
    {'&':'&',           ← 字面 '&'(不带分号)
     '<':'<',     ← 字面 '<'
     '>':'>',     ← 字面 '>'
     '"':'"', ← 字面
     "'":'''}[c]));}

源码实际值:

function esc(s){return String(s??'').replace(/[&<>"']/g,c=>(
    {'&':'&',        ← 字符:&, &, a, m, p, ;
     '<':'<',
     '>':'>',
     '"':'"',
     "'":'''}[c]));

为什么你看到"裸 &"?:

Chrome DevTools 渲染 HTML entity 时的简化 —— 浏览器把 &amp; 显示为 &(吃掉一层 entity 转换)。这是显示层行为,不是代码层。

如果你想看真实值,在 DevTools 里:

  1. 右键点击 '&' → "Edit as HTML" 会显示 &amp;
  2. 或点 "Network" → 找 help.html → "Response" 标签 → 看原始字节
