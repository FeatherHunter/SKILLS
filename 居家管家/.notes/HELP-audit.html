HELP 页面代码审计 · 5 个真实 BUG

对照 templates/help_center.html 实际渲染输出逐项排查。

BUG 1 · wrap.innerHTML += html 把 payload script 摧毁P0

位置:templates/help_center.html:<body> 段

事实:

<body>
<div class="wrap">
  <script id="payload" type="application/json">{...}</script>
  <!--SHARED-HELPERS-->
</div>
<script>
  // IIFE 读 payload + 渲染
  wrap.innerHTML += html;  ← 关键
</script>

原因:innerHTML += 等同于读出整个 wrap 子树、序列化、再插入,这个过程会丢弃 wrap 里原本已经存在的 <script> 节点(浏览器防止 innerHTML 重新执行脚本)。

后果:IIFE 中 document.getElementById('payload') 在 wrap.innerHTML += 之后能找到 — 但此时 `已变成 inert 文本节点`,某些浏览器 (Chrome) 会保留 DOM 引用但 `textContent` 仍可读,所以**测试通过的 JSON parse 不保证渲染成功**。最坏情况:整个 IIFE 静默失败,页面只显示 wrap 里的 `
