PLAN · HELP 两条改进

改进 1 · 默认全部折叠

现状:HTML 渲染时第一个 group 带 open 类,其余折叠。

改动:templates/help_center.html 的 IIFE 里"const isOpen = (i === 0) ? ' open' : '';"改为空字符串。

// 改前:
const isOpen = (i === 0) ? ' open' : '';

// 改后:
const isOpen = '';  // 默认全部折叠

用户流程:进 HELP → TOC 列表可见 → 点想用的 group 展开 → copy prompt → 折叠其他

风险:用户看不到"首屏默认有什么";但有 TOC + 64 byte 大小,top of page 就有完整索引。

工作量:1 行 JS。极低风险。

改进 2 · 按人类语言分类

你想要的"分类"可能有 3 种理解

方案一级 group粒度工作量

我的推荐:B2(任务导向)

理由:
  • 「找东西 / 存东西 / 改东西 / 看统计 / 出门回家 / 账号密码」直接对接用户大脑的"我现在要干什么"
  • 比 wake_word 维度更粗,降低 TOC 视觉压力
  • 每个 action 下挂所有相关 wake_word + 场景
