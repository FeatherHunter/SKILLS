P0-3 · 你说"很恐怖,现在数据库已经出现这个问题了吗?"

答案:你的生产数据库没问题。我没动过生产。

实测 858 FK 悬空是怎么来的:
我把生产 DB cp 到 mktemp -d 创建的临时目录,然后在临时目录里跑:
python3 scripts/category_manager.py import /tmp/seed.json --force
这只改了临时目录里的 DB,你的生产 home.db 一个字节都没动(隔离 DB 命令末尾都有 rm -rf "$T")。
风险等级(修正):P0(必须是,因为破坏性命令无二次确认),但只在你主动跑这个命令时触发。当前 100% 安全,只要你不跑 import --force。

不过 --force 命令无保护这件事仍是真问题——只是当前不是"现在有问题",是"未来某次手滑会出问题"。
