# HTML 输出命名与时间偏离(原则 12 · 本地时间 + 覆盖策略)

居家管家 Skill 的 HTML 输出在两项与 SKILL 开发总纲 §原则 12.X 显式偏离,合并记录于本 ADR,避免 SKILL.md 与 ADR 同步漂移(Q4 = A 决策)。SKILL.md §📌 输出位置 章节不再重复细节,只引用"详见 ADR-0001"。

## 偏离 1:本地时间(UTC → 本地)

居家管家 Skill 的 HTML 输出文件名时间戳用本地时间(`datetime.now()`),而非 SKILL 开发总纲 §原则 12.X 规定的 UTC。理由:本 Skill 面向个人家庭场景,用户看到文件名时间戳期望与钟表时间一致;UTC 会让下午 5 点生成的文件名上显示成 9 点,造成 8 小时偏差和混淆。卡路里/饼干记账等同性质个人场景 Skill 也可参考此决策。

## 偏离 2:直接覆盖(强制 `_N` 后缀 → 直接覆盖)

居家管家 Skill 的 HTML 输出文件名冲突策略为"同秒同名直接覆盖"(无 `_N` 后缀),而非 SKILL 开发总纲 §原则 12.A 规定的"`_N` 后缀不覆盖"。

**理由**:
- 本场景不存在"保留历史输出"的需求:运行产物已被 `.gitignore` 排除,不入 git 历史
- 同秒同名的概率性唯一冲突极低(秒级时间戳 + 单用户单进程,实测 0 冲突)
- `_N` 后缀会让用户被一堆 `_1` `_2` 后缀的旧版本文件淹没,体感差

**代价**:冲突时无 `_N` 兜底,旧版本直接消失。但本场景的旧版本没有审计价值,代价可接受。`_N` 后缀可作为兜底但默认不用,如未来出现多用户/多进程并发写入,可重新启用 `_N` 后缀。

## 代价(两项共用)

- 文件名时间戳不跨时区可比(同一时刻在不同时区生成的文件名不同),但本场景不存在跨时区协作
- 冲突时旧版本无 `_N` 兜底,但实测 0 冲突,代价可接受

## 与总纲的关系

这是对 §原则 12.X 的显式偏离。SKILL.md §📌 输出位置章节只引用本 ADR,不重复细节。如果未来总纲修订 12.X 改为"本地时间或 UTC 由 Skill 自决"+"冲突策略由 Skill 自决",本 ADR 即遵从的依据;如果总纲坚持原规定,本 ADR 是已记录的违规。
