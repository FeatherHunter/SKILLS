# HTML 输出文件名用本地时间而非 UTC

居家管家 Skill 的 HTML 输出文件名时间戳用本地时间(`datetime.now()`),而非 SKILL 开发总纲 §原则 12.X 规定的 UTC。理由:本 Skill 面向个人家庭场景,用户看到文件名时间戳时期望与钟表时间一致;UTC 会让下午 5 点生成的文件名上显示成 9 点,造成 8 小时偏差和混淆。卡路里/饼干记账等同性质个人场景 Skill 也可参考此决策。

**代价**:文件名时间戳不跨时区可比(同一时刻在不同时区生成的文件名不同),但本场景不存在跨时区协作。

**与总纲的关系**:这是对 §原则 12.X 的显式偏离。SKILL.md §📌 输出位置章节记录此偏离。如果未来总纲修订 12.X 改为"本地时间或 UTC 由 Skill 自决",本 ADR 即遵从的依据;如果总纲坚持 UTC 强制,本 ADR 是已记录的违规。
