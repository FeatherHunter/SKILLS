3验收中发现并修复的问题

① 复制数据拿不到数据(真 bug)
按钮 onclick 引用 render() 局部变量 payload,点击时已销毁 → 改挂 window.__hmPayload 全局。
② 4 个 prompt 按钮点击无效
模板字符串 \n 被解释成真实换行写进 onclick 属性 → 语法错误 → 改为 \\n 转义。

375px 下按钮文字换行或 text-overflow 省略 → 文案缩短 + nowrap + 2 列网格。
④ 徽章类名冲突
.badge.empty 撞 .empty 空态类 → 改 b-empty/b-full 独立类名。
⑤ 功能重叠/冗余
「批量设阈值」与「设置阈值」重叠(去重)· 快递单卡「标记收到」与批量重复(删除)· 换范围检测→按范围检测(新手可读)。
