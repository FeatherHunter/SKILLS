1#248 规范核心(用户 2026-08-10 拍板)

格式 = 每个需要用户填写的参数行 字段名(允许值/提示): ______
  • 提示/允许值/示例:并入字段名,括号紧贴字段名,写在冒号前
  • 填空位:下划线 ______(6 个),每行最后一个字符,后面不跟任何尾巴
  • 无提示字段:直接 字段名: ______
  • 对齐:字段名(含括号提示)用全角空格对齐,保证各行下划线在同一列
  • 适用:HELP 复制 prompt / 场景 HTML 按钮复制 prompt / 涉及用户填写的任何 prompt
  • 例外:「复制数据/复制日志」纯数据不进表单;发给人类的文本(如催还)保持自然语言
