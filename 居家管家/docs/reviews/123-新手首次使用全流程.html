SM8 · 新手完整旅程

从零开始 · 首次使用全流程

一个完全没用过的小白,从打开对话到所有配置落地,会做哪些操作?背后发生了什么?

用户操作 系统/AI 后台 判断分支
1
用户操作

说:「帮我安装居家管家技能」

小白什么都不用懂,只需把这句话发给 AI。它来自 SKILL.md 的一键安装 prompt,复制即用。

2
系统后台

AI 检查 Python 环境

确认电脑有 Python 3.x,这是运行技能的前提。缺了会提示先装。

python --version
3
用户操作

告诉 AI 数据放哪(或直接确认默认)

AI 引导配置环境变量:数据库目录 SKILLS_DB_PATH 和照片目录 HOME_PHOTOS_DIR。小白只需回答「放 D 盘」或点头用建议值。

💡 这一步配置一次,永久生效;不配置也能用(走默认路径),但数据会落在 C/D 盘隐藏目录,不好找。
4
系统后台

AI 显示当前配置并确认

回显已生效的环境变量,让用户确认无误。

SKILLS_DB_PATH = D:\2Study\StudyNotes\.db
HOME_PHOTOS_DIR = D:\2Study\StudyNotes\.db\HomeHub\photos
5
用户操作

说:「首次使用」

触发初始化工作流。这是 SKILL.md 定义的唤醒词,小白照 HELP 页面的按钮/提示说就行。

6
系统后台

AI 跑环境检测 → 生成向导 HTML

检测操作系统/Python/目录可写性/数据库状态,并渲染 6 步向导页面给用户看。

python scripts/开始使用/cli.py check → 开始使用/first_use_wizard.html
向导页面显示:环境变量配置好了吗?
✅ 已配置页面显示真实路径,直接进下一步
⚠️ 未配置页面显示「(未设置,走默认)」+ 一个「先配置环境变量」按钮
7a
用户操作 · 仅未配置时

点「先配置环境变量」→ 复制指令给 AI

按钮复制的 prompt 已自包含(技能路由+唤醒词+参数),粘贴回 AI 即可,AI 引导配置。

7b
系统后台 · 仅未配置时

AI 配置环境变量 → 重新检测 → 刷新页面

配置后重跑 check,向导页的路径变成真实值,回到主流程。

8
用户操作

确认路径(默认即确认) → 点「开始初始化」→ 复制指令发 AI

路径输入框已预填真实值,小白可改可不改;下方实时预览要复制的完整指令,点按钮复制。

9
系统后台

AI 建库 + 建分类种子(幂等)

创建数据库表结构,导入 60 个分类节点(8 顶级 + 52 二级)。重复执行不会二次破坏。

python scripts/开始使用/cli.py init → 建库 + seed_categories.yaml 60 节点
10
系统后台

状态确认(幂等判定)

确认到底建好了没有:未初始化 / 库已建 / 已初始化 三种状态。

python scripts/开始使用/cli.py init-status
11
系统后台

渲染完成向导(已完成态)

6 步步骤条全绿,显示建库结果:数据库路径 + 8 顶级分类 + 60 节点 + 种子标识。

render_开始使用.emit_sm8("first_use_wizard.html", stage=done)
12
用户操作

看到「✅ 初始化完成」→ 开始录第一批

页面提供「开始录入第一批」按钮(复制 prompt → 建议从拍照开始)。至此配置全部落地,进入日常使用。
