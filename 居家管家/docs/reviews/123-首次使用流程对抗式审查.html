首次使用流程 · 原版 vs 代码事实

原流程图有 4 处与 first_use_wizard.html 实际代码不符,并揪出 1 个模板 bug。以下是审查结论 + 修正版(HTML 交互级)。

1对抗式审查发现(原流程图错误)

❌ 错误 1:env 未配置时「只点一个按钮」

原流程图说未配置时点「先配置环境变量」按钮。但代码 (first_use_wizard.html:171-185) 显示:env 未配置时页面同时渲染 2 个表单 + 2 个按钮——「数据库目录」输入框(配置用)+「数据保存路径」输入框(初始化用),以及「先配置环境变量」+「开始初始化」两个按钮。用户有两条并行路:先配置 或 直接用默认路径初始化。原流程图只画了一条。

❌ 错误 2:HTML 其实被打开 2 次(两个不同的文件)

原流程图没区分:第一次是 AI 生成 pending 版 first_use_wizard.html(路径确认用);建库完成后 AI 重新生成 done 版(新文件,12.A 命名带新时间戳)再发给用户。不是同一文件刷新,是两个文件。

❌ 错误 3:「复制 → 回聊天粘贴」的往返没画

HTML 里的按钮只负责复制 prompt 到剪贴板(Toast 确认),真正的执行发生在聊天窗口——用户把复制的文本粘贴回对话发给 AI,AI 才跑命令。原流程图把「点按钮」当成「执行」,遗漏了中间这个关键人工步骤。

❌ 错误 4:一键安装的配置展示 vs HTML env 卡片混为一谈

步骤 4 画的配置回显是安装对话里的展示;而 env 状态卡片是 first_use_wizard.html 里的渲染 (line 132-133)。两条路径,原流程图合并了。

🔴 顺带揪出模板 bug(first_use_wizard.html:183):「数据库目录」建议值被硬编码为 D:\2Study\StudyNotes\.db —— 违反 ADR-0002 决策 4「db_path 禁止写死,环境变量实时推导」。换机器/换路径就错。需改为由 AI 渲染时注入建议值(env 检测推导),或留空让用户填。已在 ISSUE #123 追加。

2修正版 · HTML 交互级全流程

1

用户说:「帮我安装居家管家技能」

复制 SKILL.md 一键安装 prompt 发给 AI。无 HTML 打开,纯对话。

2

AI检查 Python 环境 → 引导配置环境变量

对话式完成,不渲染 HTML。用户回答目录或确认默认。

python --version → setx SKILLS_DB_PATH "..."
3

用户说:「首次使用」(唤醒词)

触发初始化工作流。AI 开始跑环境检测。

4

AI跑 check → 生成并发送 first_use_wizard.html(pending 版)

HTML #1 打开 6 步步骤条 + 环境检测卡片(OS/Python/路径/可写 + env 状态)。

python scripts/开始使用/cli.py check → 首次使用初始化_YYYYMMDD_HHMMSS_待初始化.html

判断页面 env 卡片显示什么?

SKILLS_DB_PATH 显示真实路径 → 已配置;显示「(未设置,走默认)」→ 未配置。

✅ 已配置直接走第 6 步(开始初始化)
⚠️ 未配置页面同时给出两条路 ↓
5a

HTML #1 内【仅未配置】填「数据库目录」→ 点「先配置环境变量」

数据库目录(可改,建议值) 预填建议目录;先配置环境变量 复制自包含配置 prompt → Toast「配置指令已复制」。

然后把复制内容粘贴回聊天窗口发给 AI → AI 执行 setx → 重跑 check → 重新发送 pending 版 HTML(env 卡片变真实值)→ 回到判断。

复制内容:请加载「居家管家」技能,帮我配置数据存储环境:设置 SKILLS_DB_PATH=...
5b

HTML #1 内【或】直接填「数据保存路径」→ 点「开始初始化」

数据保存路径(可改,默认即确认) 预填真实 db_path;下方实时预览完整 prompt;开始初始化(复制指令给 AI) → Toast。

然后复制内容粘贴回聊天窗口发给 AI。

复制内容:请加载「居家管家」技能,帮我完成首次使用初始化(唤醒词:首次使用):确认数据保存路径:...。请执行初始化:建库(含分类种子 60 节点)。
6

AI执行 init(建库 + 分类种子)→ init-status

聊天窗口侧执行,无新 HTML。幂等:已有库/分类 → 跳过。

python scripts/开始使用/cli.py init → init-status
7

AI生成并发送 first_use_wizard.html(done 版)

HTML #2 打开(新文件,新时间戳)步骤条全绿 + 建库结果(路径/8 顶级/60 节点)+ 「录入引导」输入框。

render_开始使用.emit_sm8(first_use_wizard.html, stage=done) → 首次使用初始化_YYYYMMDD_HHMMSS_已完成.html
8

HTML #2 内填「录入引导」→ 点「开始录入第一批」

录入引导(可改) 预填「从拍照开始,建议先录 1-3 件试用」;开始录入第一批(复制) → Toast → 复制 → 粘贴回聊天发给 AI → AI 引导录物品。

复制内容:请加载「居家管家」技能,帮我录入第一批物品(唤醒词:拍物品):从拍照开始...

3核心机制一句话

层角色
聊天窗口唯一执行层:AI 读指令、跑 CLI、生成 HTML
HTML 页面决策层:展示状态、提供可编辑参数表单、复制 prompt 回聊天(按钮只复制不执行)
往返循环HTML 复制 prompt → 聊天粘贴 → AI 执行 → 新 HTML —— 每一步操作都是一次往返
