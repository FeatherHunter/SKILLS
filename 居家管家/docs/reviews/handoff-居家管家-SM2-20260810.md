## 验收规范共识（用户拍板,后续所有 SKILL HTML 适用）

1. 复制数据/日志 = **人类可读全中文 + 无 JSON**(数组递归展开);按钮文字恒定,反馈走独立 Toast
2. 按钮: 手机端偶数一行 2 个/奇数重要按钮整行;全页 ≤3 色按功能区分;复制数据/日志单独一行
3. prompt 需填参数 = `字段名(推荐值): ______`(推荐值必须功能实际支持,禁造替代值)
4. 需用户填写的操作(新建/改名/设固定位等)= **页内表单**(可编辑+实时预览+空值拦截),禁系统弹窗
5. 撤销/回退类操作**必须精确到操作对象**(如撤销合并=逐物品清单),禁路径级粗暴回退
