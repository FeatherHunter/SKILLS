# SM3 穿搭出行域(SM3 · 6 唤醒词)

> 流程速查。所有场景:CLI 生成 HTML → 双通道交付(HTML + 一句话总结)→ 复制 prompt 闭环。

## 穿什么(穿搭推荐 · SM3-1)

1. AI 尝试获取今日天气(失败 → 告知用户,降级纯标签筛选);解析场合(不明 → HTML 内场合选择器)
2. 调 CLI 生成拼贴卡:

```bash
python3 scripts/home_manager.py sm3-outfit --temperature 28 --occasion 上班
```

3. 用户看拼贴卡(相册风):点照片看原图 / 外层·内搭切换 / 换一套(本地翻页,超出本地回 AI)
4. 用户点「今天穿这套」→ 复制 prompt 回 AI → AI 逐件 `update --id X --add-tag 已穿`/标记使用(积累穿搭历史,不建偏好档案)
5. 衣橱缺口(gap)→ 提示引导录入或加购物清单;衣橱空/太少 → 空态引导录入

## 衣橱分析(SM3-2)

```bash
python3 scripts/home_manager.py sm3-wardrobe
```

- 呈现:构成分布 + 闲置清单(无最后使用时间 → 按录入时间估算 + 「估算」徽章)+ AI 建议一句
- 闭环:勾选闲置 →【标记废弃】【送人(废弃+备注)】【先不处理】→ 复制 prompt 回 AI
- 缺口 → 「缺口加入购物清单」→ 复制 prompt 联动 SM5 购物清单

## 换季(SM3-3)

```bash
python3 scripts/home_manager.py sm3-season --season 夏季 --action 收纳
```

- 呈现:季节衣物清单(标签 夏季/冬季/春秋)+ 收纳目标位置选择(收纳位建议)
- 勾选(全选/逐条)→ 确认收纳/拿出 → 复制批量 prompt(收纳=移位置+标已收纳;拿出=状态在家+去已收纳标签)
- 无季节标签衣物 → 提示先打季节标签(标物品);旅游中等异常状态不收纳

## 带物品(SM3-4 · 带出)

```bash
python3 scripts/home_manager.py sm3-trip --trip-type 健身 --days 1 --plan-type 力量 --exercises 深蹲,卧推
```

- 行程类型:健身/出差/旅行/超市/游泳/爬山/滑雪/自定义(规则库);天数
- 健身联动两层:计划类型(力量/有氧/休息日)→ 基础物品;动作 → 护具知识表(拉力→拉力手套/练腿→腰带/卧推→手肘绷带)
- 清单物品:库内匹配(带照片)/未录入 → 「未录入」徽章 → 引导录入或加购物清单
- 出发核对:勾选装箱 + 进度 + 遗漏提示 → 复制 prompt 批量标「旅游中」

## 归物品(SM3-4 · 归位)

```bash
python3 scripts/home_manager.py sm3-trip --mode return
```

- 查所有「旅游中」→ 逐条确认归位(恢复在家)→ 复制 prompt 批量更新
- 遗漏:还有 N 件未归位 → 下次出行顺路提醒

## 旅行穿搭(SM3-5)

```bash
python3 scripts/home_manager.py sm3-trip-plan --days 5 --destination 三亚
```

- AI 获取目的地未来天气预报(失败 → 按季节估算 + 标注);每日温度传 `--temps 28,29,28,...`
- 呈现:每日穿搭(日期+天气+组合)+ 行李汇总(去重)+ 冲突提示(5 天 3 件上衣)
- 采纳某天(标记使用预填)/ 生成行李清单(→ 带物品 prompt)/ 换一天方案
