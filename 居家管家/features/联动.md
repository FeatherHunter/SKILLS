# 联动域 · 跨技能联动(SM9 · T10)

> 权威清单: `.scratch/v2.0-spec-map/scenes/SM9-联动功能.md`(3 场景定稿)
> 本文件 = 路由表引用的功能文档(SKILL.md 加载文件列)
> 本质: 跨技能协作 —— 居家管家持物品数据,卡路里/饼干记账持各自领域数据;
> 联动执行 = **复制 prompt 到对应技能(单工闭环)**,本域只做能力展示与触发引导。

## 唤醒词速览

| 唤醒词 | 场景 | CLI |
|--------|------|-----|
| 联动总览 | 联动功能总览(能力索引/偏好设置) | `sm9-overview` |
| 记到卡路里 | 食品联动(记到今日饮食/查热量) | `sm9-food --item-id N [--action log\|query]` |

| (偏好) | 联动偏好设置(频控) | `sm9-prefs --key food\|price --value ask\|remember\|off` |

## 核心概念

- **联动契约表**(`scripts/联动/ops.py` LINK_CATALOG): 3 条索引 = 食品→卡路里 / 价格→饼干记账 / 健身→出行清单(SM3-4 已实现)
- **双入口单实现**: 独立触发(本域场景)+ 录入顺路建议(1-1/1-2 回执,偏好控制);执行在业务域
- **跨技能契约(接口名以对方 SKILL.md 实际触发词为准)**:
  - 卡路里: 记饮食 →「记一餐/记吃了」;查热量 →「查食品/查热量」;健身计划 →「看今天练什么/看本周计划」
  - 饼干记账: 记支出/记收入 →「记支出」「记收入」
  - prompt 内写对方真实唤醒词,用户复制到对方技能即触发(单工闭环)
- **偏好存储**: JSON 文件 `$SKILLS_DB_PATH/link_prefs.json`(不碰 DB,D1 联动偏好表留批 #103)
- **数据诚实**: 无 seed_key(D1 才加)→ 食品判定 = 分类名关键词 + 名称启发,页面标注「按分类/名称判断,可修正」;无热量数据 → prompt 让卡路里侧查食品库补全

## 场景说明

### 联动总览(SM9-1 · 联动总览)
- 类型: 查看 + 选择
- 流程: 说话(「能联动什么」)→ `sm9-overview` → 联动清单 HTML → 复制触发 prompt / 前往业务场景 / 设偏好
- 呈现: 3 条联动条目(联动名/触发词/依赖技能/数据流/示例 prompt/前往业务场景按钮)+ 偏好设置区(每次询问/记住上次/关闭)
- 偏好落地: 用户点「应用偏好」→ 复制 prompt(「请把联动偏好设置为:food=关闭…」)→ AI 执行 `sm9-prefs`
- 分支: 无联动配置 → 空态(默认启用核心联动)

### 食品联动(SM9-2 · 记到卡路里)
- 类型: 查看 + 选择 + 回执
- 流程: 说话(「把牛奶记到卡路里」/「这个多少卡」)→ 查物品确认(`sm9-food --item-id N`)→ 动作选择 → 复制 prompt → 卡路里技能执行 → 回执
- 呈现: 目标物品确认(照片+名称+数量)+ 动作选择【记到今日饮食】【查热量】+ prompt 预览(物品名/数量/单位)
- 判定: 非食品/饮品 → 错误回执(「不是食品/饮品: 分类「XX」不在食品/饮品范围」+ 建议修正)
- 分支: 物品不存在 → 错误回执(换 ID 重试)

### 价格联动(SM9-3 · 记到记账)
- 类型: 查看 + 选择 + 回执
- 流程: 说话(「把价格记到记账」)→ 查物品确认(`sm9-price --item-id N`)→ 方向选择 → 复制 prompt → 饼干记账执行 → 回执
- 呈现: 目标物品确认(照片+名称+单价+数量+总价+记账分类)+ 方向选择【记支出】【记收入(退货退款)】+ prompt 预览(物品名/价格/分类映射)
- 价格 = 单价 × 数量(总价);分类映射表(食物与饮品→餐饮 等,未命中→其他)
- 分支: 无价格 → 错误回执(「没有价格信息」+ 建议「改物品」补录);物品不存在 → 错误回执

## 双入口 · 录入顺路建议(1-1/1-2 回执后)

录物品/拍物品完成后,AI 按偏好决定是否给联动建议(防打扰底线):

| 偏好 | 行为 |
|------|------|
| ask(每次询问) | 始终在回执顺路提醒区给出联动建议 |
| remember(记住上次) | 按上次用户是否接受联动决定(默认) |
| off(关闭) | 不打扰,不回执建议 |

- 判定: 物品是食品/饮品 → 建议「记到卡路里」(查热量/记一餐);有价格 → 建议「记到记账」(支出/收入)
- 建议内容 = `sm9-food / sm9-price` 生成的 prompt,附在回执 HTML 顺路提醒区
- 偏好设置: 联动总览页偏好区,或直接 `sm9-prefs --key food --value off`
