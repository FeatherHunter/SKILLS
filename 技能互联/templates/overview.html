§1技能接入状态

判定口径与 check_public_contract 校验器一致：登记 + 注册表文件 + skilllink --what 跑通

已接入契约一致，可被 skilllink-read 读取 未接入公开「还没接」状态，促使开发时补上 登记异常已登记但契约失效（校验器会拦住）

§2未接入技能怎么补

灰显技能接入三步走（详见 技能互联/SKILL.md 接入步骤）

1复制脚手架 scaffolds/PUBLIC_DOMAINS.py.template 到 <技能>/PUBLIC_DOMAINS.py，按契约 v1 填自己的域注册表
2在 skill_registry.yaml 登记：技能名 → 路径 + 注册表模块（只存路径，不存 DB 路径）
3跑 check_public_contract.py 全绿，本页即自动从灰变绿

§3命令速查

skilllink-read · 命令真身住技能互联 Base（契约 v1 §7）

skilllink-read --skill 作息管家 --what  # 问「你能提供什么」
skilllink-read --skill 作息管家 --domain sleep --from 2026-08-01 --to 2026-08-10  # 查数据（统一信封）
check_public_contract.py  # commit 前静态闸门：登记 ↔ 注册表双向兑现

本页由 overview_render.py 生成 · 技能互联（Skill Link）Base · 不执行任何 fetch / 不碰任何数据库
