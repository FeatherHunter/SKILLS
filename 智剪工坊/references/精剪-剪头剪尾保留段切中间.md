# 精剪 - time_segments 保留段切中间(v3.0 · D7 修订)

> **对应脚本**: `lib/video_processing.py`(`build_video_filter`)+ HTML timeline 框选
> **触发词**: "剪头"、"剪尾"、"保留某段"、"切掉中间"、"trim"、"cut"、"pin"、"clip"、"去掉广告片段"
> **v3.0 修订(2026-07-29)**:5 个该消失的 op (`trim-head` / `trim-tail` / `cut-middle` / `pin-range` / `target-duration`) **已废弃**(D7),改用 `videos[i].time_segments[]` 边界表达。
> **历史**:v1.3 严格测试 10 场景 0 偏差通过 —— 该逻辑已迁移到 `time_segments` 多段拼接。

---

## 1. time_segments 边界速查(取代旧 4 op)

| 用户想做的 | v3.0 怎么表达(JSON) | 用户操作(HTML) |
|---|---|---|
| 剪头 N 秒 | `time_segments[0].start_sec = N` | timeline 上让第一个 segment 从 N 秒开始 |
| 剪尾 N 秒 | `time_segments[last].end_sec = duration_sec - N` | timeline 上让最后一个 segment 在 duration-N 处结束 |
| 保留 [X, Y] | 单个 segment `{start_sec: X, end_sec: Y}` | timeline 上框选 [X, Y] |
| 切掉 [X, Y] | 创建相邻 segment,中间不进 JSON | timeline 上选要保留的段,中间部分标"已删段" |
| 目标时长 N | 拼接后时长 = 各段相加(无需声明) | 由 time_segments 累加自动得出 |

> **不再使用**:`videos[i].video_ops.trim-head` / `trim-tail` / `cut-middle` / `pin-range` / `target-duration`(D7 已废弃,HTML UI 移除 checkbox,JSON Schema 拒绝)。

## 2. time_segments 多段(取代 v1.x multi-range)

### 单段

```json
{
  "videos": [{
    "file": "video.mp4",
    "index": 1,
    "duration_sec": 30,
    "time_segments": [
      { "id": "seg_1_1", "start_sec": 5.0, "end_sec": 10.0 }
    ]
  }]
}
```
保留 [5, 10]。

### 多段(取并集,concat 起来)

```json
{
  "time_segments": [
    { "id": "seg_1_1", "start_sec": 5.0, "end_sec": 10.0 },
    { "id": "seg_1_2", "start_sec": 15.0, "end_sec": 20.0 }
  ]
}
```
保留 [5, 10] 和 [15, 20]。

### 自动排序与合并(HTML timeline 保证)

- 段列表自动按 `start_sec` 排序(HTML 在 serialize 前排序)
- 相邻 / 重叠段自动合并:`[5,10]+[10,15]` → `[5,15]`(相邻)
- 不重叠段保留为多个 segment(取并集)

## 3. 旧测试场景对照(v1.x vs v3.0)

| 场景 | v1.x 写法 | v3.0 写法 |
|---|---|---|
| 单段 [5,10] | `pin-range: {from: "00:00:05", to: "00:00:10"}` | `time_segments: [{start_sec: 5, end_sec: 10}]` |
| 多段 [5,10]+[15,20] | `pin-range: {ranges: [{from, to}, {from, to}]}` | `time_segments: [{5,10}, {15,20}]` |
| 切掉 [5,15] | `cut-middle: {from: "00:00:05", to: "00:00:15"}` | `time_segments: [{0,5}, {15, duration}]` |
| 剪头 3s | `trim-head: {sec: 3}` | `time_segments[0].start_sec = 3` |
| 剪尾 5s | `trim-tail: {sec: 5}` | `time_segments[last].end_sec = duration_sec - 5` |
| 目标时长 30s | `target-duration: {sec: 30}` | (无需声明,拼接后自动 = 各段相加) |

## 4. 时间格式

`start_sec` / `end_sec` 接受数值秒(数字,不是字符串):

- `5.0` — 5 秒
- `30.5` — 30.5 秒
- HTML 输入框可接受 `MM:SS` 格式(如 `"00:30"`),保存时**强制转秒**

> **不再支持**:`HH:MM:SS` / `MM:SS` / `"5分30秒"` 等字符串格式。
> 字符串格式在 v1.x 是为了用户输入方便;v3.0 统一为数字秒(规范清楚,AI 解析无歧义)。

## 5. AI 编排要点

- **AI 必读**:看到 `time_segments[]` 时,按 spec §7 校验(段不重叠、id 唯一、区间合法)
- **多段拼接需要 concat**:多 segment 时,filter 用 concat 输出
- **段区间合法性**:`0 ≤ start_sec < end_sec ≤ duration_sec`
- **空 `time_segments[]` = 整段保留**(取全集)

## 6. 实际代码示例

```python
# v3.0:HTML 写出的 time_segments
video = {
    "file": "video.mp4",
    "index": 1,
    "duration_sec": 30,
    "time_segments": [
        {"id": "seg_1_1", "start_sec": 5.0, "end_sec": 10.0},
        {"id": "seg_1_2", "start_sec": 15.0, "end_sec": 20.0}
    ]
}

# AI 编排:用 trim + concat
import subprocess
# trim 第一段
subprocess.run([
    "ffmpeg", "-y", "-i", video["file"],
    "-ss", str(video["time_segments"][0]["start_sec"]),
    "-to", str(video["time_segments"][0]["end_sec"]),
    "-c", "copy", "/tmp/seg_0.mp4"
])
# trim 第二段 + concat(省略)
```
