2 · 第一性原理(§03 变体管理)

每个核心唤醒词配 2-3 个变体 · 3 方向
3 个变体方向:
  1. 同义 — 换说法("查询" / "找一下" / "搜下")
  2. 口语 — 加口语化 token("帮我" / "给我看下" / "呢" / "哈" / "一下")
  3. 模糊 — 缺主语/语法略错/同音字("那 X 怎么找" / "X 走起" / "X 错字")
方向制 vs 硬编码:§03 明确说"标方向不写具体话,避免硬编码过期"。但 P0-4 预演显示只标方向 fresh agent 仍不会路由——需要方向 + 1-2 个参考例子。
