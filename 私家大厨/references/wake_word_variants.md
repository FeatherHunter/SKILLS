# 唤醒词变体参考(§03 变体管理 · P1-1 落地)

> **本文件是 SKILL.md 唤醒词表"变体方向"列的具体例子补充。** 标注方向不写具体话易导致 fresh agent 不会路由(见 P0-4 预演),所以<strong>方向 + 1-2 个参考例子</strong>。
>
> **避免硬编码:** 例子用于说明,不是穷举。实际用户表达会变,AI 应基于方向灵活匹配。

## 3 个变体方向(§03 标准)

| 方向 | 含义 | 典型模式 |
|------|------|---------|
| **同义** | 换说法(动词/名词替换) | "查询" / "找一下" / "搜下" |
| **口语** | 加口语化 token | "帮我" / "给我看下" / "呢" / "哈" / "一下" |
| **模糊** | 缺主语/语法略错/同音字 | "那 X 怎么找" / "X 走起" / "X 错字" |

## 5 核心词(P0-4 预演高发 · 详细覆盖)

### 1 · 开始做菜

```yaml
同义:
  - "开火做 X"          # 烹饪动作替代
  - "下厨 X"            # 口语动作
  - "做菜 X"            # 简化形式(去掉"开始")
口语:
  - "帮我下个厨,做 X 哈"   # 强口语包装
  - "给我做 X 吧"          # 礼貌 + 语气词
  - "今晚做 X 行不"         # 时间 + 征询
模糊:
  - "X 走起"              # 启动意图
  - "搞 X"                # 极简化
  - "整 X 吃"              # 动作+目的
```

**判定原则**:表达含"烹饪/启动/做"动作词 → cooking_render.py + HTML。

### 2 · 查看食谱

```yaml
同义:
  - "搜下 X 做法"          # "搜"+"做法" 双重暗示
  - "X 怎么弄"             # 口语化"弄"
  - "查 X 配方"            # 厨艺术语
口语:
  - "那 X 怎么做呢"        # 弱化"查看"+"呢"语气
  - "给我看下 X 哈"        # 礼貌+语气
  - "X 的做法给我说下"      # 完整句
模糊:
  - "X 错字(例:宫暴鸡丁)"  # 同音字
  - "X 的"                 # 极简
  - "想了解 X"             # 抽象表达
```

**判定原则**:表达含"看/查/搜/做"动作 → recipe_render.py + HTML。<br>
**错字处理**:AI 主动识别(如"宫暴"→"宫保")并提示正确结果。

### 3 · 搜索食谱

```yaml
同义:
  - "找一下 X"             # "找"替代"搜索"
  - "查 X 有哪些"           # "查"替代
  - "X 在哪"               # 位置隐喻
口语:
  - "帮我找 X 哈"          # 口语包装
  - "X 都有哪些呢"          # 完整句
  - "看下都有啥 X"          # 简化
模糊:
  - "排骨的菜有?"          # 疑问句式
  - "X 的菜有哪些"          # 隐式搜索
  - "X 类的"               # 极简
```

**判定原则**:表达"找/查/搜" + 关键词 → recipe_manager.py search + 文字列表。

### 4 · 生成清单(采购)

```yaml
同义:
  - "X 要买啥"             # "买"替代"清单"
  - "X 的购物清单"          # 完整名词
  - "买 X 要哪些"           # 疑问句
口语:
  - "帮我整下 X 的购物单子"  # "整"+"单子"
  - "X 的食材帮我列下"      # 完整
  - "X 要带啥"             # 简化
模糊:
  - "X 采购"               # 核心动词
  - "X 买"                 # 极简
  - "做 X 缺啥"             # 隐式需求
```

**判定原则**:表达"买/采购/带/缺" + 菜名 → shopping_render.py + HTML。

### 5 · 记录做菜

```yaml
同义:
  - "刚做完 X,4.5 星"      # 完整报告
  - "今天做了 X"            # 时间明确
  - "X 4 分"               # 简略评分
口语:
  - "哈,刚做完了 X,5 分,完美"  # 强口语
  - "X 做了,3.5 星吧"       # 征询
  - "刚 X 完,4 分"          # 简化
模糊:
  - "录下 X 4"             # "录"替代"记"
  - "X done"               # 中英混
  - "X 写 4"               # 极简
```

**判定原则**:表达"做完/做了/记下/录" + 菜名 + (评分) → history_manager.py add。

## 错字/同音字处理(§07 §10 s04 → 文档建议)

**当用户输入含错字**(如"宫暴鸡丁"→"宫保鸡丁"),AI 行为:

1. **主动识别** — 拼音/字形相似度匹配
2. **提示用户** — "您是不是指'宫保鸡丁'?"
3. **继续执行** — 用户确认后用正确词

**实现方式**(待 P1-3 Test 套件加单元测试):
