# 分类映射桥接表（categories-mapping.md）

> **权威声明**：本 Skill 的权威分类体系以 [`categories.md`](./categories.md) 为准（10 支出 L1 + 5 收入 L1，L1/L2/L3 三级）。
>
> [`config-cookie-accounting.ts`](../config-cookie-accounting.ts) 是 **SkillBoard 数据层视图**（legacy），独立维护；本文件仅做语义桥接，**不修改** `config-cookie-accounting.ts` 的字段，也**不修改** `categories.md` 的权威分类。

## 用途

任何读 `config-cookie-accounting.ts` 的工具（如 SkillBoard 前端）都能用本表把 **9 个 L1（legacy）** 映射到本 Skill 的 **10 个 L1（v3.1）**，避免两套分类并行漂移。

## L1 桥接表

| config-cookie-accounting.ts（legacy，9 L1） | categories.md（v3.1，10 L1） | 映射性质 | 备注 |
|---|---|---|---|
| `餐饮` | `餐饮` | **精确** | 完全一致 |
| `购物` | `居家` + `穿着` | **近似（拆分）** | legacy 把"家用消耗品"和"个人穿着"合并；本 Skill 拆为居家（家具家电/日用品）与穿着（上衣/下装/鞋包） |
| `交通` | `出行` | **改名** | 仅术语更替，语义一致；含公共交通/网约车/长途/车辆相关/骑行 |
| `娱乐` | `玩乐` | **改名** | 仅术语更替；含影音游戏/运动健身/旅游/演出赛事/户外 |
| `医疗` | `健康` | **改名** | 仅术语更替；含看病/药品/体检/保险/保健品 |
| `住房` | `居家` | **近似（并入）** | legacy 把住房单列；本 Skill 归入居家（房租水电/家具家电/日用品等） |
| `教育` | `学习` | **改名** | 仅术语更替；含课程培训/书籍/订阅/考试/工具 |
| `通讯` | `居家/通讯` | **降级为 L2** | legacy 把通讯当 L1；本 Skill 降为居家下的 L2（话费/流量/套餐/网络服务） |
| `其他` | `其他` | **精确** | 兜底完全一致 |

> 收入 L1 两边一致：`工资` / `奖金` / `兼职` / `投资` / `其他收入`（legacy 写作 `其他`，本 Skill 写作 `其他收入`，仅字面差异，语义一致）。

## 映射规则

1. **精确（餐饮 / 其他 / 工资 / 奖金 / 兼职 / 投资）** → 直接替换字符串
2. **改名（交通→出行 / 娱乐→玩乐 / 医疗→健康 / 教育→学习）** → 字符串替换 + 提示用户核对
3. **拆分（购物 → 居家 + 穿着）** → 按心法维度 3（对象是谁）二次判断：
   - 个人穿着（卫衣/T 恤/外套/裤/鞋/包/内衣袜）→ `穿着`
   - 家用消耗品（家具/家电/日用品/洗护/纸品/收纳）→ `居家`
4. **并入（住房 → 居家）** → 全部归入 `居家/房租水电`
5. **降级（通讯 → 居家/通讯）** → 改为 L2，归入 `居家`

## 字段语义差异

| 字段 | config-cookie-accounting.ts | categories.md | 说明 |
|---|---|---|---|
| L1 列表 | 9 个（含购物/交通/娱乐/医疗/住房/教育/通讯） | 10 个（含穿着/出行/玩乐/健康/学习/宠物） | legacy 缺穿着/宠物，把通讯当 L1 |
| L2/L3 | 不支持 | 支持三级（支出）/ 二级（收入） | legacy 是平铺 L1 |
| 宠物 | 无 | `宠物`（L1） | v3.1 新增（食物/医疗/用品/服务） |
| 洗护 | 归 `穿着/洗护`（已废弃） | 归 `居家/日用品/洗护` | v3.1 已迁移 |

- 若未来澄清为废弃，需独立 spec 处理；本文件仅做桥接文档
