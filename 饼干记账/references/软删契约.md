# 软删契约(公共层 · 各域不得自实现)

> 来源:G7 决议(2026-08-06 人类确认)+ G2 D-4 横切契约归属公共层。
> 实施 ISSUE A(软删)落地字段与过滤;本契约 = 行为规则,查询/分析/写入各域一律遵守,不得各自实现口径。

## 字段

- `deleted_at TEXT NULL` —— 软删时间戳;NULL = 未删,非 NULL = 已删(可追溯)

## 写入规则

| 操作 | 行为 |
|---|---|
| 撤销(新增的逆操作) | `UPDATE bills SET deleted_at = now WHERE id = ?` |
| 撤销(软删的逆操作 = 恢复) | `UPDATE bills SET deleted_at = NULL WHERE id = ?` |
| 撤销回执 | 撤销本身出回执(可再撤销,闭环) |

## 查询规则(全部查询命令默认)

- `WHERE deleted_at IS NULL` 默认过滤(各查询命令统一附加)
- 统计口径:默认不含已删;「含已删」对比为可选参数(洞察层)

## 导出/导入规则

| 路径 | deleted_at 处理 |
|---|---|
| 导出(CSV/SQL dump) | **含 deleted_at 列**(状态可完整迁移) |
| 自有备份恢复 | **原样保留**(已删恢复后仍已删) |
| 外部导入(无该列) | 列映射可选列,缺省 = NULL(未删) |

## 校验

- fixture 测试:软删后查询排除 / 恢复后可见 / 统计口径 / 导出导入保真
- 门禁 A 第 5 层:HTML 呈现与过滤一致
